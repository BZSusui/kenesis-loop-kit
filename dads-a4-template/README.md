# DADS 印刷テンプレート（A4タテ / B5タテ）

デジタル庁「ダッシュボードイメージ作成ツールキット」(16:9 pptx) のレイアウト思想をベースに、
デジタル庁デザインシステム（以下 DADS）の基本デザインへ従って印刷用に再設計した
PowerPoint テンプレートです。

**このフォルダは 2系統 × 3判型 = 6種のテンプレートを扱います。**

| 系統 | 書体 | 出力先 | いつ使うか |
|---|---|---|---|
| **DADS採用書体版** | Noto Sans JP | `dist/` 直下 | 社内・Webと書体を揃えたいとき。DADSが採用する書体そのもの |
| **標準搭載フォント版** | 和文 BIZ UDPGothic ／ 欧文 Arial | `dist/stdfont/` | **官公庁への納品・入札案件。** 先方のPCで書体が置換されない |

納品用途では **標準搭載フォント版**を使ってください。Noto Sans JP は官公庁のPCに通常入っておらず、
先方が開くと別の書体へ置換されて意図した体裁になりません。

フォルダ名は `dads-a4-template` のままですが、これは DADS-001（A4版）のコミット履歴と
ドキュメントの参照を壊さないための措置で、A4専用という意味ではありません。

| 判型 | 本文 | 版面幅 | 1行の字数 | 使いどころ |
|---|---|---|---|---|
| **A4タテ**（210 × 297mm） | 12pt | 169.3mm | 40字 | 標準の配布資料・報告書 |
| **B5タテ 標準**（182 × 257mm） | 12pt | 143.9mm | 34字 | 冊子・手に取って読む資料。文字の大きさをA4と揃えたいとき |
| **B5タテ コンパクト**（182 × 257mm） | 10.5pt | 148.2mm | 40字 | A4原稿をB5へ移すとき。1行の字数・改行位置がA4と一致する |

**このフォルダは kenesis-loop-kit の既存成果物とは独立しています。**
既存のファイル・ディレクトリは一切参照・変更していません。

> **別環境で作業を引き継ぐ場合は、まず [HANDOVER.md](HANDOVER.md) を読んでください。**
> 現在の状態・移行手順・設計判断の理由・既知の不具合・次にやる候補をまとめています。
>
> 本作業はチケット **DADS-001** で管理しています（`../tickets/active/DADS-001_*.md`）。

### 確認済みのこと / 未確認のこと

- 確認済み（A4） — 210 × 297mm（7,560,000 × 10,692,000 EMU）であること、ガイド線が版面境界に
  一致すること（`preview/guides.png`）、`build/validate.py` を無警告で通過すること、
  python-pptx で再読込できること、`preview/` の各ページの版面・余白・書体サイズ・配色。
  **Microsoft PowerPoint で開いて修復ダイアログが出ないこと、［表示］→［ガイド］でガイド線が
  版面境界に一致することを人間が確認済み**（2026-09-16）。
- 確認済み（B5 2種） — 182 × 257mm（6,552,000 × 9,252,000 EMU）であること、`validate.py` を
  無警告で通過すること、全13ページで本文がフッター罫に衝突しないこと（プレビュー画像の画素検査）。
- **未確認 — B5 2種は Microsoft PowerPoint 本体での表示を検証していません。**
  `preview/` の画像とPDFは自前レンダラーによる近似描画であり、PowerPoint の出力そのものではありません。

### 既知の不具合（修正済み）

初版で PowerPoint が「コンテンツに問題が見つかりました」と修復を要求する不具合がありました。

- 原因: スライドマスターの `<p:cSld>` に `<p:bg>`（背景）要素が2つ入っていた。既定テンプレートが持つ
  背景を除去せずに追加していたため。`<p:bg>` はスキーマ上1つまで。
- 併せて `<p:sldSz>` の `type` 属性が既定の `screen4x3` のまま実寸（A4）と矛盾していたため `custom` へ修正。
- 再発防止として `build/validate.py` を追加。要素の重複・出現順序・図形IDの一意性・
  プレースホルダーの解決可否・パッケージ整合を検査します（不具合を再注入した回帰テストで検出を確認済み）。

| 縦 | 109.2mm | 2カラム 右側の左端（ガター 8.5mm の反対側） |

## 4. 版面（グリッド）の導出

ツールキット(16:9) から測った寸法を、A4タテで DADS のレイアウト規定に合うように置き直しています。

### 4.1 ツールキット(16:9) の実測値

| 項目 | 実測値 |
|---|---|
| スライドサイズ | 12,192,000 × 6,858,000 EMU（338.7 × 190.5mm） |
| 左右マージン | 263,352 EMU ＝ 7.32mm |
| タイトル上端 | 166,774 EMU ＝ 4.63mm／18pt Bold |
| 本文エリア上端 | 692,150 EMU ＝ 19.2mm |
| 2カラム時のカラム幅 | 5,760,000 EMU ＝ 160.0mm ×2 |
| カラム間ガター | 約 137,000 EMU ＝ 3.8mm |
| フッター（名称・ロゴ） | 12pt `#626264` 右寄せ |
| フッター（注記） | 10.5pt `#626264` 左寄せ |

### 4.2 A4タテへの置き換え

DADS レイアウト規定「ガターは原則として本文文字サイズの2倍」「カラム幅は本文文字サイズの整数倍」を
**先に固定し、マージンを残差として決める**方法をとっています。

```
本文文字サイズ   16 CSS px（= 12pt）
ガター           16px × 2 = 32px = 8.467mm
カラム幅         16px × 5 = 80px = 21.167mm
カラム数         6（A4タテの幅では12カラムは細くなりすぎるため。DADSはカラム数を規定していない）

版面幅 = 6 × 21.167 + 5 × 8.467 = 169.333mm
左右マージン = (210 − 169.333) ÷ 2 = 20.333mm
```

| 項目 | A4タテでの値 |
|---|---|
| 用紙 | 210 × 297mm |
| 左右マージン | 20.333mm |
| 上下マージン | 16.933mm（余白スケール ×8） |
| 版面 | 169.333 × 221.158mm |
| カラム | 6 × 21.167mm |
| ガター | 8.467mm |
| ヘッダー領域 | 16.933 〜 44.950mm（章名 → ページタイトル → 見出し罫 0.5mm） |
| フッター領域 | 272.458 〜 280.067mm（罫 0.2mm → 注記・ページ番号） |
| 2カラム片側 | 80.433mm（3カラム分） |

### 4.3 余白スケール

DADS「余白」の規定（基準単位 8 CSS px の倍率スケールを3〜5段階に絞る）に従い、5段階に固定しています。

| 段階 | CSS px | mm | 主な用途 |
|---|---|---|---|
| ×1 | 8 | 2.117 | 見出しと直下の小見出しなど、最も近い関係 |
| ×2 | 16 | 4.233 | 見出しと罫、小見出しと本文 |
| ×3 | 24 | 6.350 | 罫と本文の開始、カード内パディング |
| ×4 | 32 | 8.467 | ガター、ブロック間 |
| ×8 | 64 | 16.933 | 上下マージン |

上下マージンは A4 が ×8（16.933mm）、B5 は ×7（14.817mm）です。
用紙高に対する比率は A4 5.701%／B5 5.765% で、判型が変わっても余白の印象が揃います。

### 4.4 B5タテへの置き換え

B5（幅182mm）に A4 の版面（169.333mm）をそのまま持ち込むと左右マージンが 6.333mm しか残らず、
印刷に耐えません。A4 と同じ手順（ガターとカラム幅を先に固定し、マージンを残差にする）で
導出し直しています。**カラム数6は3判型で共通**です。

```
B5 標準        本文 16 CSS px（= 12pt）
               ガター    16px × 2 = 32px = 8.467mm
               カラム幅  16px × 4 = 64px = 16.933mm
               版面幅 = 6 × 16.933 + 5 × 8.467 = 143.933mm
               左右マージン = (182 − 143.933) ÷ 2 = 19.033mm

B5 コンパクト  本文 14 CSS px（= 10.5pt）
               ガター    14px × 2 = 28px = 7.408mm
               カラム幅  14px × 5 = 70px = 18.521mm
               版面幅 = 6 × 18.521 + 5 × 7.408 = 148.167mm
               左右マージン = (182 − 148.167) ÷ 2 = 16.917mm
```

**なぜ2種あるのか。** 「A4と同じ比率で配置したい」という要望に対し、
版面比率と DADS の本文文字サイズ基準を同時には満たせないためです。

| | A4 | B5 標準 | B5 コンパクト |
|---|---|---|---|
| 左右マージンの比率 | 9.683% | 10.458% | **9.295%（A4に最も近い）** |
| 1行の字数 | 40字 | 34字 | **40字（A4と一致）** |
| 2カラム片側の字数 | 19字 | 16字 | **19字（A4と一致）** |
| 1ページの本文行数（行高170%） | 30.7行 | 25.8行 | 29.4行 |
| DADS の本文16px以上の基準 | 満たす | **満たす** | 例外規定に依拠（後述） |
| 本文と補助テキストの文字サイズ差 | あり | **あり** | なし（どちらも10.5pt） |

- **A4の原稿をB5へ移す**なら コンパクト版。1行の字数が同じなので改行位置が崩れません。
- **B5単独で作る**なら 標準版。文字が大きく、補助テキストとの階層も保てます。

### 4.5 コンパクト版が DADS から外れている点（重要）

コンパクト版は **DADS の規定をすべて満たしてはいません。** 次の2点で例外に依拠しています。

1. **本文 14 CSS px。** DADS は「本文やUIにおいては16 CSS px以上が基準値」「14は基本的には
   使用しません。…領域的な制約がある場合のように標準的な文字サイズの使用が難しいケースに
   おいてのみ使用される」と定めています（`foundations/typography/index.md`）。
   B5判を「領域的な制約がある場合」と解釈して採用したもので、基準の充足ではありません。
2. **「14px・行高170%」は DADS のテキストスタイル表に存在しない組み合わせ**です。
   14px を持つのは Dense系（行高130% / 120%）のみで、Standard系は16pxが最小です。
   読み物としての可読性を優先して行高170%を採っています
   （DADS が推奨する「本文行高はフォントサイズの1.5倍以上」は満たします）。
   テンプレート内では該当箇所に **※** を付け、ページ内に注記を出しています。

グリッド規定（ガター＝本文の2倍／カラム幅＝本文の整数倍）と余白スケールは、3判型とも満たしています。

## 5. タイポグラフィ

書体は DADS が採用する **Noto Sans JP**。サイズは DADS のテキストスタイル（CSS px）を 0.75 倍して pt に換算。

| 用途 | DADSトークン | CSS px | pt | 行高 | 字間 |
|---|---|---|---|---|---|
| 資料タイトル（表紙） | Dsp-48B-140 | 48 | 36 | 140% | 0 |
| 章タイトル・裏表紙組織名 | Std-32B-150 | 32 | 24 | 150% | 1% |
| ページタイトル | Std-24B-150 | 24 | 18 | 150% | 2% |
| 見出し2 | Std-20B-150 | 20 | 15 | 150% | 2% |
| 見出し3 | Std-16B-170 | 16 | 12 | 170% | 2% |
| 本文 | Std-16N-170 | 16 | 12 | 170% | 2% |
| 注記・出典・表 | Dns-14N-130 | 14 | 10.5 | 130% | 0 |
| ラベル（1行UI） | Oln-14B-100 | 14 | 10.5 | 100% | 2% |

- 行間は PowerPoint の **「固定値（pt）」**（OOXML の `<a:lnSpc><a:spcPts>`）で指定しています。
  「倍数」指定は書体の内部メトリクスに依存して CSS の `line-height` と一致しないためです。
- 字間（`letter-spacing`）も DADS の指定（0%・1%・2%）を pt へ換算して `spc` 属性に設定済みです。
- DADS が原則として許容しない 14 CSS px（10.5pt）未満は使用していません。

### フォントについて

- テーマの日本語・欧文フォントを `Noto Sans JP` に設定しています。
- **未導入の環境では PowerPoint が別の書体に置き換えます。** 行間は固定値のため行位置はずれませんが、
  字幅が変わり折り返し位置は変化します。
- 無償（SIL Open Font License 1.1）で入手できます: <https://fonts.google.com/noto/specimen/Noto+Sans+JP>
- 導入できない場合の代替としては Yu Gothic Medium（ツールキット本体が実際に使用している書体）が近くなります。

## 6. カラー

**注意：DADS の Markdown 版には HEX 値やデザイントークンの定義が含まれていません。**
含まれるのは設計原則とコントラスト比の下限のみです。したがって本テンプレートの配色は
「DADS が定める色」ではなく、**デジタル庁ダッシュボードツールキットのテーマ配色をそのまま採用し、
DADS の下限を満たしているかを実測して用途を決めたもの**です。

| 役割 | HEX | 白背景とのコントラスト比（実測） | 使用可否 |
|---|---|---|---|
| プライマリー | `#0C21BA` | 10.81 : 1 | テキスト・罫線・面 |
| セカンダリー | `#2E4EE7` | 6.25 : 1 | テキスト・罫線・面 |
| ターシャリー | `#4F7AE9` | 3.97 : 1 | 罫線・面のみ（**文字には使用不可**） |
| 淡アクセント | `#99B0EC` | 2.15 : 1 | 面の塗りのみ |
| 最淡アクセント | `#CFDCF0` | 1.39 : 1 | 面の塗りのみ |
| 補助テキスト・罫 | `#626264` | 6.09 : 1 | 補助文字・罫線 |
| 背景（淡） | `#F7F8FB` | — | 面の塗りのみ |
| 本文・見出し | `#000000` | 21.00 : 1 | テキスト |

その他の実測値:

| 組み合わせ | 比 | 用途 |
|---|---|---|
| `#000000` on `#F7F8FB` | 19.77 : 1 | 淡背景上の本文 |
| `#626264` on `#F7F8FB` | 5.73 : 1 | 淡背景上の補助文字 |
| `#FFFFFF` on `#0C21BA` | 10.81 : 1 | 濃色表紙・裏表紙の見出し |
| `#CFDCF0` on `#0C21BA` | 7.80 : 1 | 濃色表紙・裏表紙の本文 |

DADS が定める下限（テキスト 4.5:1 以上／非テキスト要素 3:1 以上）はすべて満たしています。
比率は `build/` 内の算出（WCAG 相対輝度）による実測値です。

フォーカスインジケーターの配色（Yellow-300 と Black の2重構造）は DADS が変更を禁じています。
本テンプレートは静的な印刷物用のため該当要素を持ちませんが、派生物で UI を作る場合は変更しないでください。

## 7. 使い方

1. `dist/DADS_A4_Portrait_Template.pptx` を開く。
2. 収録済みのサンプル13ページは、内容を差し替えて使うか、不要なら削除する。
3. ページを増やすときは **［ホーム］→［新しいスライド］** から上記8レイアウトを選ぶ。
   プレースホルダーには入力を促す文言が入っており、クリックして上書きできる。
4. ページ番号は右下のフィールドが自動採番する。
5. 印刷・PDF出力は **［ファイル］→［エクスポート］→［PDF/XPSの作成］**。
   用紙がすでに A4 なので倍率調整は不要。

### 崩さないでほしい箇所

- プレースホルダーの位置とサイズ（版面・グリッドの定義そのもの）
- 行間の「固定値（pt）」指定と字間
- 文字色 — コントラスト比 4.5:1 未満の色を文字に使わないこと

## 9. 再生成


```bash
python3 -m venv .venv
```

### あふれ検査（`overflow.py`）が守る範囲

サンプル本文を書き換えたり判型を足したりすると、文字がフッターへ食い込むことがあります
（B5対応のとき実際に3ページで起きました）。`rebuild.sh` はその検査を自動で行い、
見つかった時点で止まります。

| | |
|---|---|
| **守る** | フッター罫を持つページで、本文がフッター罫を越えること |
| **守らない** | テキストが枠高を超えること自体（PowerPointは枠を超えて描くのが通常で、本テンプレートにも意図した箇所がある） |
| **守らない** | 図形どうしの重なり、表の行高、画像のはみ出し、横方向のはみ出し |
| **守らない** | PowerPoint 実機での厳密な折り返し位置 |

判定は「図形の下端（アンカーを考慮）がフッター罫 + 0.5mm を越えたか」だけです。
表紙・章扉・裏表紙はフッター罫が無く、ページ下部まで要素を置く設計なので対象外です。

**この検査は PIL のフォントメトリクスによる近似で、実機確認の代わりにはなりません。**
折り返し位置は PowerPoint と厳密には一致しないため、明らかなあふれを捕まえるためのものです。
日本語フォントが無い環境では検査をスキップします（その旨を出力します）。

### 書体について

標準搭載フォント版は次の書体で構成しています。**いずれも Windows と Mac で書体名が一致する**ため、
Macで作成して Windows へ納品しても置換されません。

| 用途 | 書体 | 搭載環境 |
|---|---|---|
| 和文（`ea`） | **BIZ UDPGothic** | Windows 10 1809以降に標準搭載。モリサワ製のユニバーサルデザインフォント |
| 欧文（`latin`） | **Arial** | Windows・Mac とも標準搭載 |

**游ゴシックは採用していません。** Mac でのファミリー名は「游ゴシック体」、Windows は「Yu Gothic」で、
日本語名・英語名ともに異なります。OOXML には「見つからなければ別名で探す」という仕組みが無く、
書ける書体名は1つだけなので、**どちらの名前を指定してももう一方のOSで置換されます**（実測で確認）。

**BIZ UDPGothic 単体も採用していません。** BIZ UDP の欧文字形は横に広く、
数字や英字を含む文章で行長が伸びて版面設計（1行あたりの文字数）が崩れます。
欧文を Arial にすることで、**Noto Sans JP 版と1行の文字数が一致**します（実測で確認）。

MS ゴシックは使用していません。

> DADS は「Noto Sans JP」を採用していますが、
> 「**OSやデバイスネイティブのシステムフォントの使用を制限するものではありません**」と
> 明記しています（`foundations/typography/index.md` 20行）。書体の差し替えは DADS 準拠を外れません。

### 再生成しても差分は出ません

`rebuild.sh` は**再現可能ビルド**です。同じ入力なら同じバイト列の pptx・PDF が出るため、
中身を変えていないのに git の差分が出ることはありません。差分が出たら**本当に中身が変わっています。**

- pptx は zip 内の更新日時を `1980-01-01 00:00:00` に固定しています
- PDF は `/CreationDate` `/ModDate` を同じ日付に固定しています
- `rebuild.sh` は `PYTHONDONTWRITEBYTECODE=1` を設定し `__pycache__` を消してから走ります。
  `spec.py` を編集してもファイルサイズが変わらないとき（例: `MARGIN_U=8` → `7`）に、
  Python が古いバイトコードを使って**古い定義のままビルドしてしまう**のを防ぐためです

**A4 を変更していないつもりのときは `regress.py` が「一致」を返すことを必ず確認してください。**
意図してA4を変えた場合のみ `regress.py --update-baseline` で基準を更新します
（差分が出たときに安易に基準を更新すると、この検査は意味を失います）。

寸法・書式・判型を変えたいときは `build/spec.py` だけを編集してください。
判型は `PROFILES` に定義し、カラム幅・ガター・マージン・垂直リズムは
用紙寸法・本文サイズ・カラム倍率・マージン倍率の4項目から導出されます。

依存: `python-pptx`（生成）、`pillow`（プレビューのみ）。`.venv/` は持ち運ばないこと（OS/CPU依存）。
