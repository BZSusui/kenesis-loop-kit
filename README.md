# Kenesis Loop Kit

**Webサイトのデザインラフ（見た目の下書き）を、AIと対話しながら自動生成するツール**です。
業種・カラム構成・配色・参考実績を画面で選ぶと、外部依存ゼロの HTML を最大3案まとめて生成します。

あわせて、Claude Code で開発を進めるための**開発ループのキット**（チケット・エージェント定義・テスト）も同梱しています。

---

## できること / できないこと

### できること

| | 内容 |
|---|---|
| デザインラフの生成 | 業種・カラム・配色・テイスト・セクション構成を指定して、**最大3案を一括生成** |
| 案の比較 | 比較画面で案A/B/Cを切り替え、**表示幅（全幅 / 768px / 375px）**も切り替えて確認 |
| 部分的な作り直し | 「このHEROだけ作り直す」を番地指定で実行 |
| 配色づくり | ムードカラー ジェネレーターで、言葉と割合から配色を3案生成 |
| 実績カタログ | 過去の実績・参考サイトを登録し、業種やテイストで絞り込んで参考に選ぶ |
| カタログへの追加 | 画像をドラッグ&ドロップ → AIが自動タグ付け → **画面で確認・修正してから登録** |
| 印刷・PDF | 生成物はブラウザ印刷でそのままPDF化できる（補助表示は自動で隠れる） |

### できないこと（重要）

| | 状況 |
|---|---|
| **見本サイトのURL** | 入力欄はありますが、**現在まだ生成に反映されません**（対応予定）。参考の雰囲気を反映したいときは「参考にする素材」から実績サムネイルを選んでください |
| **生成履歴の一覧画面** | 未実装です。履歴は `mockups/{日付}_{案件名}/` フォルダがそのまま残ります |
| **メインビジュアルの実写真** | アップロードできるのは**メインビジュアル1枚だけ**です。他のアタリ枠は色面＋説明ラベルになります。URLの直接指定はできません |
| **WebP画像の取り込み** | macOS の `sips` コマンドを使うため、**macOS でのみ**動きます。Windows では JPG / PNG をお使いください |
| **スマホ専用ページの生成** | 生成物はレスポンシブなので、別ファイルは作りません。比較画面の幅切り替えで確認してください |

## 動かすのに必要なもの

| | 確認方法（macOS） | 確認方法（Windows） | 無いときは |
|---|---|---|---|
| **Python 3** | `python3 --version` | `py -3 --version` または `python --version` | macOS: `xcode-select --install` ／ Windows: [python.org](https://www.python.org/downloads/) から導入（**「Add Python to PATH」にチェック**） |
| **Claude Code** | `claude --version` | `claude --version` | [Claude Code](https://claude.com/claude-code) をインストール |
| **VSCode** | — | — | Claude Code を VSCode 上で使う想定です |

**macOS / Windows のどちらでも動きます。** ひとつだけ違いがあり、**WebP 画像の取り込みは macOS のみ**です
（変換に macOS 標準の `sips` を使うため）。Windows では JPG / PNG をお使いください。

追加のライブラリ導入（`pip install` 等）は**不要**です。Python の標準ライブラリだけで動きます。

## まず見本を開いてみる

`samples/` に、**このツールで実際に生成した見本**が3点入っています。
起動しなくても、HTMLファイルをダブルクリックするだけで開けます。

| 見本 | 見どころ |
|---|---|
| `samples/01_カフェ_1カラム/compare.html` | 王道の1カラム。**案A/B/Cの切り替え**と**表示幅の切り替え**を試せます |
| `samples/02_士業_本文2カラム/compare.html` | 本文のみ2カラム（サイドバー左） |
| `samples/03_クリニック_ナビ下配置/compare.html` | ナビをメインビジュアルの下に置いた構成 |

各フォルダの `instruction.json` は、**その見本を作ったときの指定内容**です。
「どう指定するとこうなるか」の参考にしてください。

> 見本の 🔄 セクション再生成は**使えません**（ご自身の生成物でお使いください）。詳しくは `samples/README.md`。

## はじめかた

### 1. フォルダを置く

受け取った `kenesis-loop-kit` フォルダを、**デスクトップなど好きな場所**に置きます。
フォルダ名は変えても構いません（中の仕組みはフォルダ名に依存していません）。

### 2. 起動する

`draft-gen` フォルダの中の起動ファイルを**ダブルクリック**します。

| OS | ダブルクリックするファイル |
|---|---|
| **macOS** | `draft-gen/起動.command` |
| **Windows** | `draft-gen/起動.bat` |

- ターミナル（コマンドプロンプト）が開き、ブラウザに**生成設定画面**が自動で表示されます
- 止めるときは、そのウィンドウで **`Ctrl` + `C`**

> **macOS で「開発元を検証できません」と出たとき**
> `起動.command` を右クリック →「開く」→「開く」を選んでください（初回のみ）。
> それでも開けないときは、ターミナルで `chmod +x draft-gen/起動.command` を一度だけ実行します。

> **Windows で「WindowsによってPCが保護されました」と出たとき**
> 「詳細情報」→「実行」を選んでください（初回のみ）。

### 3. 最初のデザインラフを作る

生成設定画面（自動で開きます）で、上から順に埋めます。

1. **案件名** — 保存先フォルダ名になります
2. **業種** — 一覧から選ぶか、自由入力
3. **カラム構成** — 図を見て選びます
4. **本文コンテンツ構成** — 載せるセクションを選びます
5. **配色** — 直接指定するか、「🎨 配色ジェネレーターを起動」で作った配色を貼り付け
6. **参考にする素材** — 実績カタログから2〜3枚選ぶと、雰囲気が反映されます（任意）
7. 一番下の **「この内容で生成」**

生成には数分かかります。完了すると**比較画面が自動で開き**、案A/B/Cを見比べられます。
生成物は `mockups/{日付}_{案件名}/` に保存されます。

## 画面の使い分け

| 画面 | 開き方 | 用途 |
|---|---|---|
| **生成設定** | 起動ファイルで自動 / `http://127.0.0.1:8765/` | 条件を選んでデザインラフを生成する |
| **比較** | 生成完了で自動 / `mockups/{…}/compare.html` | 案A/B/Cと表示幅を切り替えて見比べる。番地指定で部分再生成も |
| **実績カタログ** | 生成設定画面の「実績カタログを開く」 / `http://127.0.0.1:8765/catalog` | 実績の閲覧・絞り込み・追加・削除 |
| **配色ジェネレーター** | 生成設定画面の「🎨 配色ジェネレーターを起動」 | 言葉と割合から配色を3案つくる |

## 実績カタログについて

デザインラフの「参考にする素材」で選ぶ画像は、この**実績カタログ**から来ます。
カタログが空だと参考が選べないので、まずは何枚か登録してください。

### 画像を追加する

1. カタログ画面の「**実績・見本画像を追加する**」に画像を**ドラッグ&ドロップ**（またはクリックして選択・複数可）
2. 完了のお知らせが出たら「**取り込みを実行する**」
3. **AIが画像を見て**、業種・テイスト・主配色・カラム構成を推定します（**3分ほどかかります**）
4. 画面に一覧が出るので、**内容を確認・修正**します。登録したくないものは「除外する」
5. 「**この内容で登録**」で、承認した分だけがカタログに入ります

> AIの推定を**そのまま登録することはありません**。必ず画面での確認を挟みます。

### 削除する

カードの **🗑** を押すと確認画面が出ます。何を消すのかサムネイルで確かめてから削除してください。

> **削除した画像は `catalog/.trash/` に移動します。自動では消えません。**
> 完全に消したいときは、`catalog/.trash/` フォルダを Finder で開いて削除してください。
> 逆に「間違えて消した」ときは、このフォルダから取り出せます。

### 対応形式

JPG / PNG / WebP（1枚 8MB まで）。**WebP は macOS でのみ**取り込めます。

## 困ったときは

### ブラウザに画面が出ない / 「ブリッジ未起動」と表示される

起動ファイル（macOS: `起動.command` / Windows: `起動.bat`）が動いているか確認してください。
ウィンドウが閉じていたら、もう一度ダブルクリックします。

### 「python3 が見つかりません」「claude が見つかりません」と出る

起動ファイルが前提をチェックしています。表示された対処をそのまま実行してください。
Windows では `python3` ではなく `py -3` または `python` を探します。

### ポートが使われていると言われる / 前回の起動が残っている

**macOS**
```bash
lsof -nP -iTCP:8765 -sTCP:LISTEN     # 使っているプロセスを調べる
kill <表示されたPID>                  # 止める
```

**Windows**
```
netstat -ano | findstr :8765          :: 使っているプロセスを調べる（右端がPID）
taskkill /PID <表示されたPID> /F      :: 止める
```

別のポートで動かしたいときは、環境変数 `KLK_BRIDGE_PORT` を指定します。
macOS: `KLK_BRIDGE_PORT=8799 python3 draft-gen/bridge.py` ／
Windows: `set KLK_BRIDGE_PORT=8799` のあと `python draft-gen\bridge.py`。

### 「取り込みを実行」しても一覧が出てこない

AIが画像を見るのに**3分ほどかかります**。それでも出ない場合は、画面にエラーの理由が表示されます。
起動ファイルのウィンドウにも詳しいログが出ているので、あわせて確認してください。

### 生成が途中で止まる / 失敗する

生成設定画面に生成指示書（JSON）が表示されているので、それを Claude Code のチャット欄に貼り付けて Enter を押すと、同じ生成をやり直せます。

## 開発ループを回す人へ

このキットには、Claude Code で開発を進めるための仕組みも入っています。

| | 場所 |
|---|---|
| 運用ルール | `CLAUDE.md`（**作業開始前に必ず読み込まれます**） |
| 要件定義 | `docs/SPEC.md` |
| 画面設計 | `docs/wireframes/` |
| チケット | `tickets/`（雛形は `tickets/Templates/`） |
| エージェント定義 | `agents/`（investigator / architect / implementer / tester / reviewer） |
| 生成規約 | `.claude/skills/draft-generate/templates/DRAFT_RULES.md` |

主なコマンド（Claude Code のチャットで実行）:

```
/spec-interview    要件定義書を対話でつくる
/wireframe-gen     SPECからワイヤーフレームを生成する
/new-ticket        チケットを作る
/start-loop        開発ループを開始・再開する
/metrics           ループの進行状況を見る
```

テストを流すには（`tests/` を含む配布物の場合）:

```bash
python3 -m unittest discover -s tests     # macOS
python -m unittest discover -s tests      # Windows
```

## 取り扱いの注意

- **`catalog/` の中身は社外秘です。** 実績画像・案件名・タグを含みます。このフォルダの外へ持ち出さないでください
- **収集見本（`ref`）は第三者の著作物です。** 社内の参考目的にのみ使い、公開・再配布・そっくりな再現はしません
- **`mockups/` の生成物にも案件名が入ります。** 取り扱いにご注意ください
- `catalog/` `mockups/` `tickets/` は **Git の管理対象外**です。バックアップは各自でお願いします
- 生成物・カタログとも、**外部のサーバーには一切送信されません**（すべて手元のPCの中で完結します）
