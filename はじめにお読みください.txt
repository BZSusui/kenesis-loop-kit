  デザインラフ・ジェネレーター  セットアップ手順書
  （Kenesis Loop Kit）

このフォルダを開いたら、まずこの手順書をお読みください。
所要時間は、必要なものが入っていれば 2〜3分です。


------------------------------------------------------------------------------
 1. これは何か
------------------------------------------------------------------------------

条件を選ぶだけで、デザインのたたき台（ワイヤーフレーム）を3案まとめて作る道具です。

できあがるのは HTML ファイルで、ブラウザで開けばそのまま見られます。
印刷や PDF 保存もできます。写真の部分は「アタリ枠」になります。

  ★このフォルダだけで動きます。
    GitHub からリポジトリを取ってくる必要はありません。

  ● どこに置くか（Windows の方はご注意ください）

    【Mac】 どこでも構いません。デスクトップでも共有フォルダでも動きます。

    【Win】 ★「 \\ 」で始まる場所からは起動できません。
            Windows のしくみ上、\\サーバー名\共有名\... や \\wsl.localhost\... に
            置いたままでは、起動.bat をダブルクリックしても動きません。

            ・共有フォルダを使う場合 … ドライブ文字（Z: など）を割り当ててから開く
            ・いちばん確実なのは    … C:\ の下（デスクトップなど）へコピーする
            ・WSL の中に置く場合    … 起動.bat は使わず、WSL のターミナルで

                  python3 draft-gen/bridge.py

              を実行してください。そのあとブラウザで  http://localhost:8765/  を開きます。

 2. 必要なもの（2つだけ）
------------------------------------------------------------------------------

  (1) Python 3
  (2) Claude Code

どちらも入っていない場合は「4. 入っていなかったとき」をご覧ください。

  ● 入っているかの確認

    【Mac】  「ターミナル」を開いて、次を1行ずつ貼り付けて Enter
    【Win】  「コマンドプロンプト」を開いて、次を1行ずつ貼り付けて Enter

        python3 --version      ← Windows では  python --version
        claude --version

    どちらもバージョン番号が出れば準備完了です。「3. 起動する」へ進んでください。


------------------------------------------------------------------------------
 3. 起動する
------------------------------------------------------------------------------

  【Mac】
      このフォルダの中の  起動.command  をダブルクリック

      ※ 初回だけ「開発元を確認できないため開けません」と出ることがあります。
         ツールの不具合ではありません。ダウンロードしたファイルに macOS が
         印を付けるためです。次のどちらかで一度だけ許可してください。

         (1) 起動.command を Control キーを押しながらクリック（右クリックでも可）
             →「開く」→ もう一度「開く」

         (2) (1) で開けないとき（新しい macOS ではこちら）
             いちどダブルクリックして警告を閉じたあと、
             アップルメニュー → システム設定 → プライバシーとセキュリティ を開き、
             下のほうの「"起動.command" は開発元を確認できないためブロックされました」
             の横にある「このまま開く」を押す

         （2回目からはダブルクリックで開きます）

      ※ それでも開けないときは、ターミナルで次を1回だけ実行してください。
         このフォルダを Finder で開き、ターミナルに「chmod +x 」と打ってから
         起動.command をターミナルの窓へドラッグ＆ドロップして Enter。

  【Windows】
      このフォルダの中の  起動.bat  をダブルクリック

      ※ 「WindowsによってPCが保護されました」と出たら
         「詳細情報」→「実行」を選んでください。

  ● 起動すると

      黒い画面（ターミナル／コマンドプロンプト）が出て、
      少ししてからブラウザに設定画面が自動で開きます。

      ★黒い画面は閉じないでください。
        これがブラウザと生成をつないでいます。作業が終わったら閉じて構いません。

  ● 使い方

      同じフォルダの  使い方マニュアル.html  をダブルクリックしてください。
      画面ごとの操作を図つきで説明しています。

 4. 入っていなかったとき
------------------------------------------------------------------------------

  ● Python 3

    【Mac】 最初から入っていることがほとんどです。
            入っていなければターミナルで次を実行すると入ります。

                xcode-select --install

    【Win】 https://www.python.org/downloads/ からインストーラを入れてください。
            ★インストール画面の「Add Python to PATH」に必ずチェックを入れてください。
              ここを忘れると、起動.bat が Python を見つけられません。

  ● Claude Code

    社内で利用手続きが必要な場合があります。導入方法は情報システム担当、
    または AI利用管理責任者にご確認ください。

    インストール後、一度ターミナル（コマンドプロンプト）で

        claude

    と実行し、ログインを済ませておいてください。
    ログインが済んでいないと、生成のときに失敗します。

 5. すでに kenesis-loop-kit を持っている方へ
------------------------------------------------------------------------------

  ご自身の環境に kenesis-loop-kit のリポジトリを clone 済みの場合、
  この配布フォルダとは **別物として並べて置いて構いません**。

      ・この配布フォルダ … 触ればすぐ使える完成品。設定は要りません
      ・clone したリポジトリ … 開発用。テストや設計書が入っています

  同時に両方を起動すると、待ち受けポート（既定 8765）がぶつかります。
  片方を別のポートで動かすには、ターミナルで次のように起動してください。

      【Mac】  KLK_BRIDGE_PORT=8766 ./起動.command
      【Win】  set KLK_BRIDGE_PORT=8766 && 起動.bat

  なお、この配布フォルダで作ったものを clone 側へ持っていく必要はありません。
  作ったものは、この配布フォルダの中の  mockups  フォルダに残ります。


------------------------------------------------------------------------------
 6. うまくいかないとき
------------------------------------------------------------------------------

  まず次の3つをお試しください。たいていはこれで戻ります。

      (1) 黒い画面が開いたままか確認する。閉じていたら起動しなおす
      (2) ブラウザを再読み込みする
      (3) それでもだめなら、黒い画面を閉じて起動しなおす

  症状ごとの対処は  README.md  の「困ったときは」にまとめてあります。

      ・ブラウザに画面が出ない／「ブリッジ未起動」と表示される
      ・「python3 が見つかりません」「claude が見つかりません」
      ・ポートが使われていると言われる
      ・生成が途中で止まる／失敗する

  ★作ったものが消える心配はありません。
    生成したラフは  mockups  フォルダに残ります。
    起動しなおしても、ブラウザを閉じてもなくなりません。
