# [KLK-134] 置き場所の前提が案内されていない 設計

## 1. 目的

Windows で「`\\` で始まる場所に置くと起動できない」という制約を、**起動時と文書の両方**で伝える。
レビューでは一式が WSL 側に置かれており、起動できない理由が分からないまま時間が費やされた。

## 2. 現状

```
\\wsl.localhost\... に置いた 起動.bat をダブルクリック
  → cmd.exe は UNC パスをカレントにできない
  → cd /d "%~dp0" が失敗
  → 「【エラー】リポジトリのフォルダへ移動できませんでした。」だけが出る
  → 置き場所が原因だと分からない
```

文書側はさらに悪く、**誤った案内**が入っていた。

| 文書 | 記述 | 問題 |
|---|---|---|
| `はじめにお読みください.txt` | 「社内の共有フォルダに置いても、デスクトップに置いても構いません」 | `\\サーバー名\...` の形では Windows で起動できない |
| `README.md` | 「`draft-gen` フォルダの中の起動ファイル」 | KLK-105 で最上位へ移したのに古い記述が残っていた |
| `使い方マニュアル.html` | 「フォルダの中の `draft-gen` を開きます」 | 同上 |

## 3. 設計方針

**「起動時に気づかせる」と「置く前に分かる」の両方をやる。** 片方だけでは足りない。

- 起動時: `起動.bat` が **`cd` より前に** `%~dp0` の先頭2文字を見る。`\\` なら専用の案内で止める
- 置く前: 3つの文書すべてに条件と対処を書く（読者が見る場所は1つではない）

**代替案と却下理由:**

| 案 | 却下理由 |
|---|---|
| `pushd`（UNC を一時ドライブへ割り当てる）で動くようにする | 動いてしまうと、生成物の場所や claude の実行が別の問題を起こしうる。**実機で確かめられない今、挙動を増やす方が危ない**。まず「理由が分かって止まる」を確実にする |
| 文書だけ直す | 読まずに置く人が必ずいる。起動時に気づけない |
| `起動.bat` の失敗メッセージを充実させるだけ | `cd` の失敗は他の理由でも起きる。**原因別に出し分けられない** |

> `pushd` 方式は、実機で確認できる状態になってから改めて検討する（申し送り）。

## 4. 実装詳細

**`起動.bat`**（CP932+CRLF のまま編集・KLK-132）
```bat
set "KLK_HERE=%~dp0"
if "%KLK_HERE:~0,2%"=="\\" (
  echo 【エラー】ネットワーク上の場所から起動されています。
  echo 場所: %KLK_HERE%
  echo 対処1: C:\ の下（デスクトップなど）へコピーする
  echo 対処2: 共有フォルダならドライブ文字（Z: など）を割り当てる
  echo 対処3: WSL の中なら bat を使わず  python3 draft-gen/bridge.py
  pause
  exit /b 1
)
cd /d "%~dp0" || ( ... 場所を表示して案内 ... )
```
> ★判定は **`cd` より前**に置く。後ろだと「移動できませんでした」としか出ない。
> ブロックの中では `echo` と `exit` だけを使う（`set` を入れると遅延展開の問題が出る）。

**文書3つ**
- `はじめにお読みください.txt` … 誤った一文を「どこに置くか」の節へ置き換え。Mac は自由、Win は条件つき
- `README.md` … 起動ファイルの場所を最上位に訂正し、置き場所の注意を追加
- `使い方マニュアル.html` … 同じ訂正と、`warn` ブロックで注意を追加

**検査 `tests/site/check_klk134.py`（8項目）**

| ID | 内容 |
|---|---|
| E1 | ★判定が `cd` より前にある |
| E2 | 案内が3つの対処を示す |
| E3 | どこから起動したかを表示する |
| E4-E6 | 3文書すべてに条件・対処・WSL の代替手順がある |
| E7 | 「どこに置いても構わない」と読める古い記述が残っていない |
| E8 | 起動ファイルの場所の記述が最上位になっている（KLK-105 の反映漏れ） |

ラッパー（8テスト）は、判定ブロックが**ブリッジを起動せずに終わる**こと、
入れ子括弧の落とし穴を踏んでいないこと、`起動.bat` が CP932+CRLF のままであることも見る。
