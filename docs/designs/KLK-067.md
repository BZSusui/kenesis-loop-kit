# [KLK-067] 主配色をパレット準拠の16種へ 設計

## 1. 目的

カタログのタグ付け（主配色）と配色生成（ムードカラー ジェネレーター）が別の語彙を使っている状態を解消し、
**両者が同じ言葉を話す**ようにする。理恵さんの要望に基づく。

## 2. 現状

| | 語彙 | 数 |
|---|---|---|
| `palette/index.html` の `const COLORS` | レッド/ピンク/オレンジ/イエロー/イエローグリーン/グリーン/ミント・水色/ブルー/ネイビー/パープル/ブラウン/ベージュ/ゴールド/シルバー/モノトーン/**カラフル** | 16 |
| カタログ主配色 `CANONICAL_COLORS` | グリーン/ブルー/レッド/ゴールド/ピンク/モノトーン/**マルチカラー** | 7 |

現行7種はすべて16種に含まれる（`マルチカラー`＝`カラフル` の別名）。
**追加9色・改名1色**で揃う。

## 3. 設計方針

**採用する方針: palette の `const COLORS` を語彙の正とし、その `name` をそのまま採用する。**

- 順序も palette に合わせる（並びが違うと「準じている」ことが目で確認できない）。
- **`マルチカラー` は `カラフル` へ改名**する。準拠するなら名前も揃えるのが筋であり、
  2つの名前が並存すると「どちらを使うのか」という新しい迷いを生む。
- **`カラフル` の意味は変えない**: 単独指定のみ・§5.1 では表引きせず指定色へフォールバック。

### 3.1 §5.1 変換表の hex（新規9色）

palette の HSL から導出し、**主色（`--m-main`）として使える帯**へ寄せる。
帯は既存6色の実測値から決めた（S ≤ 0.55 / L 0.34〜0.52。ピンクとゴールドは既存値を尊重して例外）。
生の HSL をそのまま使うと `#41BDC8` のように既存と明らかに質感が違う色になるため、この正規化を入れる。

| カテゴリ | hex | 出自 |
|---|---|---|
| レッド | `#B3402F` | 既存（不変） |
| ピンク | `#E86FA0` | 既存（不変） |
| オレンジ | `#C87F42` | 新規（palette h28 から導出） |
| イエロー | `#BFA23C` | 新規（h48） |
| イエローグリーン | `#7E9B45` | 新規（h80） |
| グリーン | `#2E7D6B` | 既存（不変） |
| ミント・水色 | `#3E9AA6` | 新規（h185） |
| ブルー | `#2C5F8A` | 既存（不変） |
| ネイビー | `#2A3C6B` | 新規（h225） |
| パープル | `#6F4E9C` | 新規（h275） |
| ブラウン | `#885A3A` | 新規（h25） |
| ベージュ | `#A98E60` | 新規（h38・主色に使えるよう暗めへ） |
| ゴールド | `#C6A15B` | 既存（不変） |
| シルバー | `#7C858D` | 新規（h210 低彩度・主色に使えるよう暗めへ） |
| モノトーン | `#444850` | 既存（不変） |
| カラフル | （表引きしない） | フォールバック（旧マルチカラー） |

**既存6色の hex は1つも変えない。** golden `klk034` が `ブルー`/`ゴールド` の表引き結果を固定しているため。

### 3.2 データ移行

`catalog.json` の `マルチカラー`（5件）を `カラフル` へ置換する。**作業前にバックアップを取る。**

**代替案と却下理由:**

| 案 | 却下理由 |
|---|---|
| `マルチカラー` の名前を残したまま16色化する | palette に「準じる」という要望に対して中途半端。2つの名前が並存し、どちらを使うか迷う |
| 両方を受理する（別名対応） | 検証・フィルタ・表引きのすべてに分岐が増える。実データはたった5件で、移行のほうが安い |
| 新規9色の hex を生の HSL から使う | 既存6色と質感が揃わない（`#41BDC8` 等）。主色として使うには明るすぎるものもある |
| 既存6色の hex も palette の HSL から作り直す | golden `klk034` の表引き結果が変わり、生成側の回帰テストを巻き込む。**利得がない** |

## 4. 実装詳細

### 4.1 定義（3箇所・語彙の写しは checker で一致を強制）

- `draft-gen/bridge.py` … `CANONICAL_COLORS`（set）＋ 順序つきの `CANONICAL_COLORS_ORDER`（list）
- `draft-gen/catalog.html` … `CANONICAL_COLORS`（フィルタチップ・承認フォーム）
- `draft-gen/index.html` … `CANONICAL_COLORS`（参考サムネの colors 軽検証）

### 4.2 SCR-004 のフィルタチップ

16色。各チップに色見本（`.sw` の背景）を §4.1 の hex で付ける。
`カラフル` は既存の `マルチカラー` と同じ conic-gradient を流用する。

### 4.3 規約・ワイヤー

`CATALOG_RULES.md`（主配色7カテゴリ → 16カテゴリ）・`catalog-import/SKILL.md`・
`draft-generate/SKILL.md`・`DRAFT_RULES.md` §5.1・`docs/wireframes/SCR-004-catalog.html`。

### 4.4 golden fixtures

`tests/fixtures/klk034b/`（instruction.json ＋ index-a/b/c ＋ compare）の `マルチカラー` を `カラフル` へ。
**fallback の挙動自体は変わらない**ので、置換のみで golden の意味は保たれる。
