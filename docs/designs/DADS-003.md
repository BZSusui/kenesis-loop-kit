# [DADS-003] テンプレートの溢れ検査を常設する 設計

## 1. 目的

各ページのテキストが枠に収まっているかを機械的に判定する `build/overflow.py` を常設し、
`rebuild.sh` に組み込む。DADS-002 で一時スクリプトによって発見した「フッターへの衝突」を、
今後は自動で検知できるようにする。

## 2. 現状

| 仕組み | 守る範囲 |
|---|---|
| `validate.py` | pptx の構造（PowerPointが修復を要求する不整合） |
| `regress.py` | A4の出力が意図せず変わっていないこと |
| **無い** | **各ページの内容が枠に収まっていること** |

`render_preview.py` の `draw_text()` は、描画に先立ってテキストの必要高さ `total` を計算している。
しかし `total` は関数内のローカル変数で、外から取得できない（investigator F1・F4）。

## 3. 設計方針

### 採用する方針: `render_preview.py` から高さ計算を切り出し、`overflow.py` と共有する

```python
# render_preview.py（追加）
def layout_text(txBody, box, lst_default, anchor_default="t"):
    """折り返し後の行リストと必要高さを返す。描画はしない。"""
    return lines, total

def draw_text(dr, txBody, box, lst_default, anchor_default="t"):
    lines, total = layout_text(txBody, box, lst_default, anchor_default)
    ...  # 以降は現行の描画処理
```

```python
# overflow.py（新規）
# 各図形について layout_text() で必要高さを求め、枠高と比べる
```

**この方針を採る理由:**

1. 折り返しのロジックが1箇所に保たれる。複製すると `render_preview.py` 側の改修で
   判定が静かに乖離する（検査が嘘をつく状態になるのが最も避けたい）
2. 画素を見ないため、閾値が不要（L4解消）、表紙・裏表紙の誤検出なし（L2解消）、
   ディセンダーの拾い上げなし（L3解消）
3. 横方向のはみ出しは折り返しによる行数増として高さに現れるため、L1 も実質カバーできる

**代替案と却下理由:**

| 案 | 却下理由 |
|---|---|
| 画素検査（DADS-002の一時スクリプト）を常設する | L1〜L4 の限界をそのまま抱える。閾値に根拠がない |
| `overflow.py` に高さ計算を複製する | `render_preview.py` の折り返しが変わると判定が乖離する。検査が信用できなくなる |
| pptx の自動調整（`normAutofit`）に任せる | テンプレートは自動縮小を使わない方針。縮小されると版面の文字サイズ規定が崩れる |

### 判定の基準

図形ごとに次を満たさないものを「あふれ」とする。

```
必要高さ（layout_text の total） <= 枠高 + 許容値
```

- **許容値は 0.5mm**（PIL と PowerPoint のフォントメトリクス差を吸収する最小限の緩衝）
- 対象は**テキストを持つ図形のみ**。表（`graphicFrame`）は行高が内容で決まるため対象外
- プレースホルダは、スライド側に `a:xfrm` が無ければレイアウトから座標を継承して判定する
  （`render_preview.py` の既存の継承解決をそのまま使う）

**本文領域からの逸脱も併せて見る。** 枠内に収まっていても、枠自体がフッター罫を越えていれば問題なので、
図形の下端（枠上端＋必要高さ）が `FRULE_Y` を越えたページも報告する。

### 守る範囲と守らない範囲（READMEに明記する）

| | |
|---|---|
| 守る | テキストが枠高を超えること。枠の中身がフッター罫へ食い込むこと |
| 守らない | PowerPoint 実機での厳密な折り返し位置。**PIL のフォントメトリクスによる近似であり、実機確認の代わりにはならない**（investigator F6） |
| 守らない | 図形どうしの重なり、表の行高、画像のはみ出し |

### フォントが無い環境の扱い

`render_preview.py` の `font()` は日本語フォントが無いと `SystemExit` を投げる（F5）。
`overflow.py` は**この場合「検査せずスキップ」とし、終了コード0で「検査できなかった」旨を出力する**。

理由: pptx の生成と `validate.py` はフォント無しで動く、という現在の性質
（`HANDOVER.md` §3.4）を壊さないため。フォントが無いだけでビルドが止まるのは過剰である。
ただし**スキップしたことが目立つように出力する**（黙って通さない）。

## 4. 実装詳細

**ファイル構成:**
```
dads-a4-template/build/
├── render_preview.py   ← 変更: draw_text から layout_text を切り出す（描画結果は変えない）
├── overflow.py         ← 追加
└── rebuild.sh          ← 変更: 各判型のプレビュー生成後に overflow.py を実行
```

**`overflow.py` のインターフェース:**

```
usage: python build/overflow.py <pptx> [<pptx> ...]

  各pptxの全スライドを検査し、あふれた図形を「slideNN / 図形名 / 必要高さ / 枠高」で列挙する。
  1件でもあれば終了コード 1。フォントが無い環境では検査をスキップし 0 を返す。
```

**処理フロー:**
```
1. pptx を開き、スライドごとに図形を走査する（レイアウト継承を解決）
2. テキストを持つ図形について layout_text() で必要高さを求める
3. 必要高さ > 枠高 + 0.5mm なら「枠あふれ」として記録
4. 枠上端 + 必要高さ > FRULE_Y なら「フッターへの食い込み」として記録
5. 1件でもあれば一覧を出力して終了コード 1
```

**`rebuild.sh` への組み込み位置:** 各判型の生成・検証・プレビューの後、判型ごとに実行する。
`set -e` によりあふれを検出した時点で止まる。

## 5. 影響範囲

| 対象 | 影響 | 対応方針 |
|---|---|---|
| `build/render_preview.py` | 変更（関数の切り出し） | **描画結果が1ピクセルも変わらないこと**を、切り出し前後のPNGのバイト比較で確認する |
| `build/overflow.py` | 追加 | — |
| `build/rebuild.sh` | 変更 | 判型ごとに overflow.py を呼ぶ |
| `dist/*.pptx` | 影響なし | `render_preview.py` は pptx 生成に関与しない。`regress.py` で担保 |
| `README.md` | 変更 | 使い方・守る範囲・守らない範囲 |

## 6. リスク

| リスク | 深刻度 | 軽減策 |
|---|---|---|
| 関数の切り出しでプレビュー描画が変わる | medium | 切り出し前のPNGを退避し、切り出し後と**バイト単位で比較**する。1ピクセルでも違えば実装の誤り |
| 許容値0.5mmが緩すぎる／厳しすぎる | medium | 現在の3判型39ページで誤検知が出ないこと、かつ意図的なあふれを検出できることの両方で確かめる |
| 検査が「常に成功」する状態に陥る（判定が壊れても気づけない） | **high** | **意図的にあふれさせた版で検出できることを実証する**（受け入れ基準。`regress.py` と同じ手順） |
| フォント無し環境でスキップされ、検査したつもりになる | medium | スキップ時はその旨を明示して出力する |

## 7. マイグレーション戦略

| Phase | 内容 | 完了条件 |
|---|---|---|
| 1 | `render_preview.py` から `layout_text()` を切り出す | プレビューPNGが切り出し前とバイト単位で一致 |
| 2 | `overflow.py` を追加 | 現在の3判型39ページで「あふれなし」と判定 |
| 3 | 検出能力の実証 | サンプル文章を増やした版で検出され、終了コード1になる |
| 4 | `rebuild.sh` へ組み込み・README更新 | `rebuild.sh` が完走し、受け入れ基準を満たす |

## 8. ロールバック戦略

```bash
git revert {マージコミットのハッシュ}   # [DADS-003][REVERT] 溢れ検査の追加を取り消し
```

`overflow.py` を削除し `rebuild.sh` から呼び出しを外せば、DADS-002 時点の挙動に戻る。

## 9. 受け入れ条件

チケット本文の受け入れ基準を正とし、設計の観点から次を補足する。

- [ ] `layout_text()` の切り出し前後で、3判型すべてのプレビューPNGがバイト単位で一致する
- [ ] `draw_text()` は `layout_text()` を呼ぶだけになり、折り返しロジックが2箇所に存在しない
- [ ] 許容値（0.5mm）とその根拠がコード内のコメントに書かれている
- [ ] フォントが無い環境ではスキップし、スキップした旨を出力して終了コード0で返す
