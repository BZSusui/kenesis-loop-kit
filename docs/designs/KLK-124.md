# KLK-124 セクション型を図解アイコンで選べるようにする（設計・検証）

**状態**: 設計と検証のみ。実装は次回以降（理恵さんの指示・2026-09-14）

## 1. 何を作るか

理恵さんの要望:

> 生成後のモックをセクション別に再生成させる際、選択できる6型の現状の英語だけの表記から
> 簡単な図解アイコンなどを用いてもっと直感的にわかりやすく見せられる方法はないか。
> カラム別レイアウトのアイコンのように分かりやすい図解のようなものがあったほうが良い

現状: KLK-117 で日本語ラベルは付いた（`価格表／料金プラン（price-table）`）。
次はそこへ**図解**を足したい。手本は SCR-001 の「カラム構成」の図（入れ子 span ＋ CSS）。

## 2. 調べて分かったこと

### 2.1 型を選ぶ場所は **2箇所**ある

| 画面 | 場所 | 現状の表示 |
|---|---|---|
| SCR-002（比較画面） | 🔄 セクション再生成 の `<select id="regen-type">` | **日本語ラベル付き**（KLK-117） |
| SCR-001（生成設定） | ページ構成 → 行ごとの「設定 ▾」→ レイアウト型 | ★**英語マーカーのみ**（KLK-117 が未適用） |

**KLK-117 は compare.html にしか入っていない。** SCR-001 側は今も `pat-cards` と出る。
図解を入れるなら両方そろえる。ラベルだけ先に SCR-001 へ広げるのは小さく切り出せる。

### 2.2 ★最大の制約: `<option>` には図が入らない

両方とも `<select>` である。`<option>` は HTML を描けないので、
**アイコンを出すにはセレクタ自体を作り替える**（SCR-001 のカラム図と同じ「カード選択」型へ）。
ここが「大きな作業」の正体であり、絵を描く手間ではない。

### 2.3 84型は **21通りの骨格**に収まる（実測）

規約 §12.1.2／§12.1.3 の説明文を機械分類した結果:

| 骨格 | 型数 |
|---|---|
| 縦積み | 16 |
| グリッド | 16 |
| （骨格語なし＝個別対応が要る） | 10 |
| タブ切替＋表 | 5 |
| 横スクロール | 5 |
| 縦積み＋交互 | 5 |
| 縦積み＋タブ切替 | 4 |
| その他14通り | 23 |

→ **84枚を手描きする必要はない。** 部品の組み合わせ（レシピ）で描ける。

## 3. 検証したこと（試作を実際に描いた）

`scratchpad/proto/icons.html`（試作・リポジトリには入れていない）で
**18型をレシピから描画**し、実ブラウザで確認した。

- 部品: 画像枠 `.b` / 本文行 `.t` / 見出し `.hd` / タブ `.tab` / 帯 `.band`
- 骨格: `grid` / `rows` / `split` / `table` / `tabs` / `scroll` / `mosaic`
- レシピ例: `'pat-cards': {kind:'grid', cols:3, cell:'img+2'}` ← **1行で1型**
- 外部画像なし・SVG なし・入れ子 div と CSS のみ（NFR-005 を満たす）

### 分かったこと

| 結果 | 内容 |
|---|---|
| ✅ 実現可能 | 18型が **72px 幅**でも判別できた（実際のピッカー想定サイズ） |
| ✅ 手間が小さい | レンダラ1本＋レシピ84行。手描き84枚より桁で軽い |
| ⚠ 要調整1 | 円形は `aspect-ratio:1` を与えないと**楕円**になる（試作で発生・修正済み） |
| ⚠ 要調整2 | `pat-slider`（横スクロール）は**手がかりが弱い**。切れ端や矢印など別の合図が要る |
| ⚠ 未確認 | 似た型の描き分け（`voice-cards` と `sns-cards` など）は未検証。**残り66型で要精査** |

## 4. 実装の段取り（提案）

小さく切って、途中で止めても価値が残る形にする。

| 段 | 内容 | 規模 |
|---|---|---|
| **第1段** | SCR-001 の型選択にも**日本語ラベル**を出す（KLK-117 の横展開） | 小 |
| **第2段** | アイコンのレンダラ＋レシピを作る。**まず SCR-002 のセレクタをカード選択へ** | 中 |
| **第3段** | SCR-001 の行ごとの設定にも同じピッカーを入れる | 中 |
| 第4段 | 似た型の描き分けを詰める（残り66型の精査） | 中 |

第1段だけでも「英語だけ」は解消する。第2段から図解が入る。

## 5. 実装時に気をつけること

- **compare.html は固定テンプレート**（KLK-103）。生成側は書かない。
  `draft-gen/compare_template.html` を直し、`make_compare.py` が書き出す
- 送る値は**マーカーのまま**（`desiredType`）。KLK-117 の不変条件
- 「（現在）」の表示・型を持たない番地（NAV/FOOTER/CTA）の扱いを壊さない
- レシピの正をどこに置くか。ラベルは `bridge.py` の `SECTION_TYPE_LABELS`（KLK-117）にある。
  アイコンは**画面側**に置くしかない（描画だから）ので、
  **型の集合がずれないことを検査で担保する**（`check_klk117` と同型）
- 検査は**実際に描いて**確かめる。`tools/verify-responsive.node.js` と同じ流儀で、
  「84型すべてにアイコンが出る」「同じ絵が2つ無い」を実描画で見るのが望ましい
