# [KLK-036] GALLERY プール化＋スライダー（§12.1.3 土台）設計

> architect 生成。KLK-036 に対応。implementer・tester・reviewer が参照する。

## 1. 目的

HERO/MENU/GALLERY/ABOUT の見た目バリエーションを増やす第2弾。理恵さんの合意（2026-07-27）で
**「土台＋GALLERYスライダー先行」**とし、本チケットは **GALLERY をプール方式へ移行する汎用土台（§12.1.3）を確立し、
実需確定の横スライダー型 `pat-slider` を1つ追加**する（GALLERY 3→4型）。HERO/MENU/ABOUT の同機構への移行と型量産は
後続チケット（KLK-037+・理恵さんのサムネ／デザインビジョンを設計入力にする）。

## 2. 現状

investigator 調査（チケット実装メモ 2026-07-27）より:

  **型・並び順(data-section-order)・区切り・整列シグネチャ**を同時に決める（型だけの軸ではない）。
- §12.1.2（VOICE/FLOW/STAFF）: archetype を見ず (columns×navPosition→offset→割り当て) の表引き。3セクション共通 index・

  GALLERY 現3型は pat-grid 6/pat-wide 3/pat-mosaic 3。

- §14 のプール再付与は VOICE/FLOW/STAFF のみ（GALLERY 用は無い）。

## 3. 設計方針

**採用: §12.1.3「単セクション独立プール」を新設し、GALLERY を最初の適用先にする（案Y＝archetype 骨格温存）。
GALLERY 型を4型プール化し、選択は (columns×navPosition→offset) を §12.1.2 のオフセット表と共有しつつ、
割り当ては GALLERY 専用の巡回窓 `(o, o+1, o+2) mod 4` で行う。offset0→(0,1,2)=(pat-grid,pat-wide,pat-mosaic) を維持し、
既存 golden（1col×top）の GALLERY マーカーを不変に保つ。**

### 3.1 なぜ §12.1.3（単セクション独立プール）を新設するか
- §12.1.2 は「3セクション共通 index・制約A（型数一致N=6）」が本質。GALLERY を単独で4型にすると型数が非対称になり
  §12.1.2 の共有機構には乗らない。→ **セクション独立・型数自由**の新機構が要る。
- archetype（§12.1/§12.1.1）は並び順・区切り・整列という §12.1.x が持たない軸を担うため**骨格として残す**（案Y）。
  §12.1.1 の「archetype→型」表のうち **GALLERY 行だけ §12.1.3 に移譲**（HERO/MENU/ABOUT の行は据え置き＝後続で移譲）。
- §12.1.3 は将来 HERO/MENU/ABOUT も各自のプール（型数独立・mod N_section）で載せられる汎用土台にする。

### 3.2 offset0 基準の維持（既存 golden 不変）
- 割り当て `(o, o+1, o+2) mod 4`。offset0→(0,1,2)。GALLERY index0=pat-grid/1=pat-wide/2=pat-mosaic は
  §12.1.1 の archetype 固定（案A=pat-grid/案B=pat-wide/案C=pat-mosaic）と**一致**。
  → 1col×top（offset0）の既存 golden（klk023/034/034b）は GALLERY マーカー不変。golden HTML の更新は不要。
- checker のロジック（enum・期待値算出）だけを「archetype固定」→「§12.1.3 表引き」に更新する（値は変わらないが正の出どころが変わる）。

**採用しなかった代替案:**
| 案 | 却下理由 |
|---|---|
| §12.1.2 に GALLERY を統合（制約A で4セクション即N=6化） | HERO/MENU/ABOUT も即6型化が必要＝重い。並び順/区切りの退避設計も要る。段階性に反する |
| archetype 固定のまま GALLERY だけ型を増やす（archetypeに4型目を紐付け） | archetype は3値なので4型目に案が割り当たらない。3案 distinct と両立しない |
| offset の割り当てを (0,1,2) 以外にする | 既存 golden（1col×top）の GALLERY が変わり klk023/034/034b の更新が必要になる。offset0=(0,1,2) 維持が最小影響 |

### 3.3 GALLERY 型プール（4型・index0=最頻＝従来定番）
| index | マーカー | 内容（実CSS差） |
|---|---|---|
| 0 | `pat-grid` | 均等グリッド（`grid-template-columns:repeat(3,1fr)` 等・現行） |
| 1 | `pat-wide` | 横帯ワイド（現行） |
| 2 | `pat-mosaic` | 大小モザイク（`grid` + span 強弱・現行） |
| 3 | **`pat-slider`（新）** | 横スクロール/カルーセル（`display:flex; flex-wrap:nowrap; overflow-x:auto` ＋各 `flex:0 0 <幅>`・スナップ）。cat-0008/0029 の実需 |

`pat-slider` の実CSS は voice-slider/staff-hscroll と同系（横スクロール）だが GALLERY 語彙・独自クラス。飾りにしない（N7/R4 同型検査）。

### 3.4 割り当て・到達可能性
- オフセット表（§12.1.2 と共有・DRAFT_RULES.md 現行の12セル・値域0-5）。
- GALLERY 割り当て（§12.1.3・巡回 mod 4）: offset0→(0,1,2) / 1→(1,2,3) / 2→(2,3,0) / 3→(3,0,1) / 4→(0,1,2) / 5→(1,2,3)。
- 案A の index = offset%4 → 全 offset{0..5} で {0,1,2,3} を網羅（pat-slider=index3 は offset3 の案A で到達）。
- 各行連続3窓 → 3案 distinct（N=4≥3）。
