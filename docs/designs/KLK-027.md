# [KLK-027] セクション見出し・リード文の事前指定 設計

> architect生成のチケット単位設計書。KLK-027 に対応。implementer/tester/reviewer が参照する。

## 1. 目的

クライアントの簡易ワイヤーにある各セクションの見出し・リード文を**そのまま**ラフへ写せるようにする
（文言事前指定ロードマップ第2段）。MVコピー（KLK-024）と同じ「指定があれば最優先・無ければAI提案」の原則を
セクション単位へ拡張する。

## 2. 現状

- `sectionOptions`（KLK-022）: セクション個別設定の map。現在は `CTA.purpose/label` のみ。bridge はキーが
  SECTION_KEYS であることを検証済み。
- `copy.mvCatch/mvLead`（KLK-024）: MV限定の指定コピー。純関数 `sanitizeCopy`（CRLF正規化・制御文字除去・
  trim・上限切詰め）が純ロジック領域にある。
- セクション見出しは各セクションの `h2`（＋小ラベル `.en`）。リード文の定位置は無い。
- section チェックボックスには change リスナーが無い（collectInput が生成時に読むため機能上は足りている）。

## 3. 設計方針

**`sectionOptions.{KEY}` に `heading` / `lead` を追加する（KLK-024 と同型の「指定時のみ」後方互換）。**

- **スキーマ**（version:1 据置・追加キーのみ）:
  ```jsonc
  "sectionOptions": {
    "ABOUT": { "heading": "私たちについて", "lead": "小さな工房から始まった、手仕事の店です。" },
    "MENU":  { "heading": "できること" },
    "CTA":   { "purpose": "contact", "label": "お問い合わせはこちら", "lead": "…" }   // purpose/label と併用可
  }
  ```
  - `heading`: 最大40字・**1行**（改行はスペースに畳む）。`lead`: 最大200字・**改行可**。
  - **指定があるときのみ**キーを出す。`sections` に無い KEY への指定は無視（bridge は sections 連動検証を既存どおり）。
- **生成規則（DRAFT_RULES §4.2）**:
  1. `heading` → 該当セクションの**見出し（`h2`）にそのまま**（AIが言い換えない）。小ラベル `.en` は従来どおりAI。
  2. `lead` → 見出しブロック直下に **`<p class="sec-lead">`** を出力（`\n`→`<br>`）。**無指定なら `.sec-lead` 自体を
     出さない**（additive・既存ゴールデン不変）。
  3. HTMLエスケープ（textContent 相当）・**複数案でも全案共通**・無指定フィールドは §4 本則でAI提案。
- **UI（SCR-001・「本文コンテンツ構成」カード内）**: 「セクションの文言」欄を新設。**選択中のセクションぶんだけ**
  入力行（セクション名＋見出し input＋リード input）を動的描画する `renderSectionCopyRows()`。
  - チェック増減で再描画。**再描画前に既入力値を退避→復元**（入力消失防止）。
  - 行ラベルは既存チェックボックス label のテキストを再利用。入力は `maxlength` 40/200。
  - section チェックボックスに change リスナーを追加（再描画＋render）。
- **入力整形**: `sanitizeCopy` を再利用。heading は `\n`→スペース置換で1行化。
- **bridge 検証**（sectionOptions ループ内・存在時のみ・全KEY共通）: heading=str・非空・≤40・制御文字なし／
  lead=str・非空・≤200・改行以外の制御文字なし。

**代替案と却下理由:**

| 案 | 却下理由 |
|---|---|
| `copy` に `sections: {KEY: {…}}` を入れ子 | セクション個別設定の置き場は `sectionOptions` が既設（KLK-022）。二重の置き場は混乱のもと。KLK-024 設計書も sectionOptions 拡張を予告済み |
| 14セクション×2欄を静的に並べる | 過密で実用に耐えない。選択中のみ動的描画にする |
| lead を `.en`（小ラベル）に上書き | `.en` は装飾ラベルでリード文の器ではない。新クラス `.sec-lead` を定義する方が意味も検証も明確 |

**buildInstruction 追加（純ロジック・sectionOptions 組み立ての直後）:**
```js
// KLK-027: セクション見出し/リードの事前指定（選択セクションのみ・指定時のみキー出力）
const texts = (input.sectionTexts && typeof input.sectionTexts === 'object') ? input.sectionTexts : {};
sections.forEach(function (key) {
  const t = texts[key] || {};
  const heading = sanitizeCopy(t.heading, 40).replace(/\n/g, ' ').trim();  // 見出しは1行
  const lead = sanitizeCopy(t.lead, 200);
  if (heading || lead) {
    const opt = sectionOptions[key] || (sectionOptions[key] = {});
    if (heading) opt.heading = heading;
    if (lead) opt.lead = lead;
  }
});
```

**collectInput 追加:** `#sectionCopyList [data-sec-key]` の各行から `sectionTexts = {KEY: {heading, lead}}` を収集。
