# [KLK-040] HERO/ABOUT を各6型へ拡充 設計

> architect 生成。KLK-040 に対応。implementer・tester・reviewer が参照する。

## 1. 目的
理恵さん要望（2026-07-28）: HERO/ABOUT を各4→6型へ。HERO に `center-scroll`/`panel-band`、ABOUT に `img-circle`/`img-zigzag` を追加。
§12.1.3 の割り当てを型数別 mod へ一般化（GALLERY=mod4・HERO/ABOUT=mod6）。KLK-035（VOICE系6型化）と同型。

## 2. 現状（investigator 2026-07-28）
- §12.1.3 割り当ては現状「4型共通 mod4」（check_klk034 GALLERY_ASSIGN を全セクション共有）。
- §12.1.2 の ASSIGN(mod6) = HERO/ABOUT 6型でそのまま使える値。
- HERO 整列（check_klk037 HERO_SIG）現4型。klk036 offset3 は現 (3,0,1)。
- offset0（klk023/034/034b）の HERO/ABOUT は (0,1,2)＝mod6でも不変。

## 3. 設計方針
**HERO/ABOUT を6型化。割り当てを型数別 mod（GALLERY=mod4・HERO/ABOUT=mod6）へ分離。offset0=(0,1,2)維持で既存不変、
klk036(offset3)=(3,4,5) で案B/Cを新型へ・案A(overlap/img-overlap)不変・GALLERY(mod4)不変。到達可能性は klk023∪klk036 で6型網羅。**

### 3.1 型プール（6型・index0=最頻）
| section | 0 | 1 | 2 | 3 | 4（新） | 5（新） |
|---|---|---|---|---|---|---|
| HERO | full | split | band | overlap | **center-scroll** | **panel-band** |
| ABOUT | img-left | img-right | img-top | img-overlap | **img-circle** | **img-zigzag** |
（GALLERY は4型のまま: pat-grid/pat-wide/pat-mosaic/pat-slider）

### 3.2 割り当て（型数別 mod・オフセット表§12.1.2共有）
- GALLERY: mod4（{0:(0,1,2),1:(1,2,3),2:(2,3,0),3:(3,0,1),4:(0,1,2),5:(1,2,3)}）＝現状維持。
- **HERO/ABOUT: mod6**（{0:(0,1,2),1:(1,2,3),2:(2,3,4),3:(3,4,5),4:(4,5,0),5:(5,0,1)}＝§12.1.2 と同値）。
- offset0→(0,1,2) 維持（既存不変）。案A index=offset%N。offset{0..5}(3col×top=5含む) で HERO/ABOUT index{0..5} 全到達。

### 3.3 HERO 整列シグネチャ6型（全distinct・機械検証 H6/S5/S4）
| 型 | (justify-content, align-items, text-align) | 意図 |
|---|---|---|
| full | (center, center, center) | 全面中央 |
| split | (space-between, center, left) | 左右分割 |
| band | (flex-end, flex-start, left) | 下寄せ帯 |
| overlap | (flex-start, center, left) | せり出し重ね |
| **center-scroll** | **(space-between, center, center)** | 全面ビジュアル＋キャッチ上/スクロール誘導↓下（上下分散・中央） |
| **panel-band** | **(flex-end, center, center)** | 上部パネル並び＋下部中央キャッチ |
（6三つ組すべて distinct・確認済み）

### 3.4 新型CSS（実CSS差＝grid/flex・モバイル畳み）
- **center-scroll**: `.m-hero` 基底 `display:flex; flex-direction:column; justify-content:space-between; align-items:center; text-align:center; min-height:420px`。上に `.catch/.lead`、下に `.scroll-cue`（↓＋"Scroll"）。背景は全面ビジュアル（atari 色面 or gradient）。モバイルは padding 縮小。
- **panel-band**: `.m-hero` 基底 `display:grid; grid-template-rows:auto auto; justify-content:flex-end; align-items:center; text-align:center`。上段 `.hero-panels`（`display:grid; grid-template-columns:repeat(3〜4,1fr)` の画像タイル並び）＋下段 `.hero-text`（中央キャッチ）。モバイルはパネル2列。
- **img-circle**: `.m-about.img-circle { display:grid; grid-template-columns:1fr 1fr; align-items:center }`＋`.atari { border-radius:50%; aspect-ratio:1 }`（円形）。モバイル1列。
- **img-zigzag**: `.m-about.img-zigzag { display:flex; flex-direction:column; gap }`＋各段 `.ab-row { display:grid; grid-template-columns:1fr 1fr }`＋`.ab-row:nth-child(even) .atari { order:2 }`（左右交互複数段）。モバイル縦積み・order解除。
