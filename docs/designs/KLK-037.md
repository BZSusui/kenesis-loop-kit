# [KLK-037] HERO/ABOUT のプール化＋オーバーラップ型追加 設計

> architect 生成。KLK-037 に対応。implementer・tester・reviewer が参照する。

## 1. 目的

理恵さんの要望（2026-07-28）: HERO/ABOUT に新型 **overlap（せり出し横長画像＋白背景文言の重なり）** を追加。
KLK-036 で確立した **§12.1.3（単セクション独立プール）**に HERO/ABOUT を移譲し、各3型→4型・index3=overlap を足す。
overlap は従来の img-left/right（横並び・重ならない）と印象が大きく変わり、HERO/ABOUT 両方で使える高頻度型。

## 2. 現状（investigator 調査 2026-07-28）

- §12.1.3 は汎用機構（GALLERY が第1適用・DRAFT_RULES:635-690）。HERO/ABOUT はセクション別プール表＋割り当て表を追記して載せる。
- **ABOUT**＝GALLERY同型（追加結合なし・素直）。
- **HERO固有リスク**＝整列シグネチャ(justify-content/align-items/text-align)が data-hero に結合（check_klk021 S5・check_klk023 S4）。
  既存: full=(center,center,center)/split=(space-between,center,left)/band=(flex-end,flex-start,left)。overlap は**第4の非重複組**が必須。
- §12.2 DEFAULT_1211 から HERO/ABOUT 除去→§12.1.3 基準へ（MENU のみ残る）。offset0 は不変。
- **golden**: offset0（klk023/034/034b）不変。**klk036（offset3）は HERO/ABOUT がプール窓(3,0,1)へシフト→再生成＋check_klk036 G9 失効対応が必要**。

## 3. 設計方針

**採用: HERO/ABOUT を §12.1.3 に追加（GALLERY と同じ割り当て mod4・オフセット表§12.1.2共有・offset0=(0,1,2)維持）。
overlap は grid実装（`grid-template-columns` で css_layout_rule を通す・重なりは transform+z-index）。HERO overlap の整列三つ組は
第4の組 `(flex-start, center, left)` を割り当て（既存3型と非重複＝S5/S4維持）。klk036(offset3) を HERO/ABOUT も overlap を含む形へ更新。**

### 3.1 §12.1.3 への追加（GALLERY と同型・型数独立）
- **HERO プール（4型）**: index0=`full` / 1=`split` / 2=`band` / 3=`overlap`
- **ABOUT プール（4型）**: index0=`img-left` / 1=`img-right` / 2=`img-top` / 3=`img-overlap`
- 割り当て表は GALLERY と同一（mod4・6行・offset0→(0,1,2)…offset3→(3,0,1)…）。オフセット表は §12.1.2 共有。
- offset0（1col×top）で (full,split,band)/(img-left,img-right,img-top)=(0,1,2)＝既存 golden 不変。

### 3.2 overlap の見た目・実装（grid＋重なり）
**HERO overlap（画像右せり出し・文言左から重なる／理恵さんの cat-0047 例）:**
```html
<div class="m-hero" data-hero="overlap">
  <div class="hero-img atari">…（横長画像アタリ・右側）</div>
  <div class="hero-text"><h1 class="catch">…</h1><p class="lead">…</p><span class="hero-cta">…</span></div>
</div>
```
```css
.m-hero.overlap { position: relative; display: grid; grid-template-columns: 1fr 1fr; align-items: center;
  justify-content: flex-start; text-align: left; min-height: 340px; padding: 0; color: var(--m-text); background: none; }
.m-hero.overlap .hero-img { grid-column: 2 / 3; grid-row: 1; align-self: stretch; min-height: 300px; }   /* 右にせり出す画像 */
.m-hero.overlap .hero-text { grid-column: 1 / 2; grid-row: 1; z-index: 1; justify-self: start; align-self: center;
  background: rgba(255,255,255,.92); padding: 32px 36px; margin-left: 24px; max-width: 460px;
  box-shadow: 0 8px 30px rgba(0,0,0,.12); transform: translateX(28%); }   /* 左から白背景・画像に重なる */
.m-hero.overlap .catch { color: var(--m-main); text-shadow: none; }
/* モバイル: 重なり解除・縦積み */
@media (max-width:640px){ .m-hero.overlap{ grid-template-columns:1fr; } .m-hero.overlap .hero-text{ transform:none; margin:-40px 16px 0; } .m-hero.overlap .hero-img{ grid-column:1; } }
```
- **整列三つ組 = (flex-start, center, left)**。既存 full/split/band と非重複（justify が flex-start＝唯一）→ S5/S4 の 3案 distinct を維持。

**ABOUT overlap（img-overlap・画像左せり出し・文言右から重なる／cat-0050 例）:**
```html
<div class="m-about img-overlap">
  <div class="atari">…（横長画像・左側）</div>
  <div class="txt"><h3>…</h3><p>…</p></div>
</div>
```
```css
.m-about.img-overlap { position: relative; display: grid; grid-template-columns: 1fr 1fr; align-items: center; }
.m-about.img-overlap .atari { grid-column: 1 / 2; grid-row: 1; min-height: 220px; align-self: stretch; }   /* 左画像 */
.m-about.img-overlap .txt { grid-column: 2 / 3; grid-row: 1; z-index: 1; background: rgba(255,255,255,.94);
  padding: 28px 32px; box-shadow: 0 8px 30px rgba(0,0,0,.12); transform: translateX(-28%); }   /* 右から白背景・画像に重なる */
@media (max-width:640px){ .m-about.img-overlap{ grid-template-columns:1fr; } .m-about.img-overlap .txt{ transform:none; margin:-40px 16px 0; } }
```
- `grid-template-columns`/`grid-column` を持つので css_layout_rule（飾り禁止 S8/G6相当）を通る。重なりは transform+z-index。

### 3.4 代替案と却下理由
| 案 | 却下理由 |
|---|---|
| overlap を position:absolute だけで実装 | css_layout_rule（grid/flex/order）に引っかからず「飾り」判定でFAIL。grid実装なら grid-template-columns で通る |
| overlap の整列を band と同じ (flex-end,…) にする | S5/S4 の3案distinctがindex3窓でFAIL。第4の非重複組 (flex-start,center,left) を割り当てて回避 |
| klk036 を触らず新 golden だけ追加 | klk036 は offset3 の唯一の fixture。HERO/ABOUT が offset3 でプール窓に乗る以上、klk036 の期待値は必ず変わる。更新不可避 |
| HERO/ABOUT/MENU を一括で §12.1.3 化 | MENU は今回の要望外。スコープを HERO/ABOUT に限定（段階的・理恵さん方針） |
