# [KLK-072] アタリ枠の比率統一 設計

## 1. 目的

画像アタリが「横に長細い帯」になる問題を根本から直す。
比率を規約で定め、`min-height` 依存をやめる。

## 2. 現状

アタリ枠は `min-height` で高さだけを決めており、**幅はコンテナ任せ**。
そのためサイドバー（狭い）では細長く、全幅では潰れる。生成物9ファイルで `aspect-ratio` は3箇所のみ。

masonry は規約に「隙間なく矩形に収める」とあるが、**`dense` の性質を誤解した記述**だった。
`dense` は既に空いた穴を後続タイルで埋めるだけで、**タイルが足りなければ最終行は空く**。

## 3. 設計方針

**採用する方針: 規約に「既定比率」を1箇所定め、例外を表で列挙する。**

- 既定 `aspect-ratio: 4 / 3`。`min-height` は**下限としてのみ**併用可。
- 例外は**型の定義そのものが別の形を前提にしているもの**に限る（正方系・HERO 全面・panel-band）。
- masonry は「意図」ではなく**手順**を書く（span 合計を列数の倍数に／端数は最後のタイルで埋める）。

**なぜ 4/3 か**: 一般的な写真は横長だが `16/9` は細すぎる。`4/3` は正方に近く、
狭い幅でも帯にならない。実績カタログの参考画像とも整合する。

**代替案と却下理由:**

| 案 | 却下理由 |
|---|---|
| 型ごとに個別に比率を書く | 型は50以上ある。書き漏れが必ず出るし、既に「map-top: aspect-ratio 横長」という曖昧な記述が生まれていた |
| `min-height` を増やして縦を稼ぐ | 幅が変われば比率は変わる。サイドバーと全幅で見え方が別物になる根本原因が残る |
| `16/9` にする | 「横に長細くならないように」という要望に反する |
| masonry を通常グリッドに変える | ベントー型の魅力（大小混在）が失われる。穴は構成の問題であり型の問題ではない |
| panel-band も 4/3 にする | KLK-043 で理恵さんの要望により意図的に 3/2 にした型。勝手に戻さない（要確認事項として残す） |
