# [KLK-073] 型ごとの調整 設計

## 1. 目的

見本の目視で出た「型の微調整」5件を、**個別の手当てではなく規約**で解決する。
同じ問題が別の型でも起きないようにする。

## 2. 現状と原因

いずれも「**器の都合で中身が壊れる**」種類の不具合だった。

| # | 症状 | 原因 |
|---|---|---|
| 1 | 2カラムページで VOICE の写真が 64px の帯 | カード内部のレイアウトが**規約に無く**、生成側の裁量だった |
| 2 | FLOW の番号枠が間延び | `grid-template-columns: 1fr 1fr` で半々 |
| 3 | キャッチが不格好に折り返す | `<br>` は正しい。**白背景が固定幅**で二重折り返し |
| 4 | キャプションが意図した位置で改行されない | AI が文言を書く場合の**改行規律が無かった** |
| 5 | SCROLL ↓ が反応しない | ただの `<div>`。リンクではない |

## 3. 設計方針

**採用する方針: 「判断の分かれ目」を規約に書き、生成側が迷わないようにする。**

- **1 は §8.1（カラム構成）に書く。** 型の問題ではなくレイアウトの帰結だから。
  同じ型でも 1col では横並びが読みやすく、2col では縦積みでないと成立しない。
  型プールに書くと50以上の型すべてに書く必要があり、必ず漏れる。
- **2・3 は型定義に書く。** その型固有の作り込みだから。
- **4 は §4.1.1（新設）に書く。** §4.1 は `copy` 指定時の規律しか無く、
  **AI が自分で文言を書くときの改行**が抜けていた。
- **5 は §4.3.1（新設）に書く。** JS を使わない同一ページ内アンカーで実装する。

**代替案と却下理由:**

| 案 | 却下理由 |
|---|---|
| 1 を型ごとに書く | 対象は voice/news/faq/price/contact/map など多数。書き漏れが必ず出る |
| 1 をモバイル規律（`@media`）で兼ねる | 2カラムページの PC 表示が直らない。モバイルとは別の問題 |
| 3 で `<br>` を消して自動折り返しに任せる | 行組が幅次第で毎回変わる。デザインラフとして見せられない |
| 5 を JS で実装する | §13 が「JS は原則不要」を掲げている。アンカーで足りる |
| 5 の飛び先を本文カラムの先頭にする | `2col-*` で**サイドバーが画面外に取り残される**。次に現れる塊＝`.m-layout` を指すべき |

## 4. 実装詳細

| 箇所 | 変更 |
|---|---|
| **§8.1（新設）** | 狭い本文カラムでの畳み方。横並び禁止・縦積み・列数削減・4/3 維持・モバイルとは独立 |
| **§4.1.1（新設）** | AI が文言を書く場合の改行。句点で改行・キャッチ最大2行・器の幅を内容にあわせる |
| **§4.3.1（新設）** | SCROLL ↓ はクリックできること。同一ページ内アンカー・飛び先・対象型 |
| `flow-zigzag` | 番号枠を正方形に。`1fr 1fr` が間延びする理由と、画像を置くなら 4/3 の分岐 |
| `flow-vertical-split` | 番号枠を正方形に |
| HERO `overlap` | 白背景をキャッチにあわせて可変に。二重折り返しの理由を実例つきで |
| `center-scroll` | §4.3.1 への参照 |
| `SKILL.md` | §8.1 / §4.1.1 / §4.3.1 への参照 |
