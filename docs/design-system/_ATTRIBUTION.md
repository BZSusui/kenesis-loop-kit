## 成果物に出典を記載する場所

DADSを参照して作った成果物には出典表記が必要です。記載場所は次のとおり運用します。

| 成果物 | 記載場所 |
|---|---|
| `docs/SPEC.md` | セクション10（参考資料）に出典行を記載 |
| `docs/designs/{ID}.md` | DADSを参照した設計は「Proposed Design」に参照パスと出典行を記載 |
| `docs/wireframes/*.html` | 冒頭コメントおよび `index.html` のフッタに出典行を記載 |
| 実装コード | UIコンポーネントの実装ファイル冒頭コメント、または `README` / `NOTICE` に集約して記載 |

DADSの記述をそのまま転記せず**自プロジェクト向けに調整した場合**は、出典行に加えて
「デジタル庁デザインシステムウェブサイト https://design.digital.go.jp/dads/ のコンテンツを加工して作成」
の旨を必ず併記する。

## 更新手順

DADSはリビングスタンダード（β版）であり随時更新されます。差し替える場合:

1. https://design.digital.go.jp/dads/resources/ から最新のMarkdown ZIPを取得する
2. `docs/design-system/` の本文ファイルを差し替える（`_` 始まりの補助ファイルは残す）
3. このファイルのバージョン・取得ZIP・配置日を更新する
4. `updates/` 配下の更新履歴を読み、既存の `docs/designs/` や `docs/wireframes/` に影響する
   コンポーネントの仕様変更・名称変更がないか確認する（例: v2.17.1 では
   「パンくずリスト」→「パンくずナビゲーション」の名称変更があった）
