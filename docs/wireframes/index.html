レビューのしかた

  1. 各カードの「画面を開く」をクリックすると、その画面のワイヤーフレームが開きます。
  2. 「PC/スマホ比較」を押すと、パソコンでの見え方とスマートフォン(幅375px)での見え方を並べて確認できます。
  3. SCR-002 では、案A/B/Cのボタンで案を切り替えられます。ブラウザの印刷プレビュー(⌘/Ctrl+P)を開くと、番地ラベルなどの補助表示が消えて提出用のPDFイメージになります。
  4. 直したい点は「SCR-001 の配色欄をもっと大きく」のように、画面番号と場所を添えて教えてください。スマホ表示だけ直したい場合は「スマホ表示で」と添えてください。
