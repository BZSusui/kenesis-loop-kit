# 見本（samples）

このフォルダには、**Kenesis Loop Kit で実際に生成したデザインラフ**が入っています。
手で書いたものではなく、`draft-gen` の生成設定画面から作った実物です。

起動しなくても、**HTMLファイルをダブルクリックするだけ**で開けます。

## 入っているもの

| フォルダ | 見どころ |
|---|---|
| `01_カフェ_1カラム/` | 王道の1カラム構成。**案A/B/Cの切り替え**と**表示幅（全幅 / 768px / 375px）の切り替え**を試せます |
| `02_士業_本文2カラム/` | 本文のみ2カラム（サイドバー左）。士業向けの堅実な構成 |
| `03_クリニック_ナビ下配置/` | ナビゲーションをメインビジュアルの下に置いた構成。スタッフ紹介・診療の流れつき |

各フォルダの中身:

| ファイル | 内容 |
|---|---|
| `compare.html` | **まずこれを開いてください。** 3案を切り替えて見比べる画面 |
| `index-a.html` / `index-b.html` / `index-c.html` | 各案の原寸（印刷・PDF化はこちらから） |
| `instruction.json` | **その見本を作ったときの指定内容**。「どう指定するとこうなるか」の参考に |

## ご注意

- **🔄 セクション再生成は、見本では使えません。**
  この機能はご自身が生成したもの（`mockups/` の中）に対して働きます。
  見本を開くと「**見本では使えません**」と表示され、ボタンは押せない状態になります（何も壊れません）。
- **案件名はすべてダミー**です（「サンプルカフェ」など）。実在の企業・店舗ではありません。
- 見本は**実績カタログを使わずに**生成しています。カタログが空の環境でも、
  `instruction.json` の内容をそのまま指定すれば同じものを作れます。

## 自分で作ってみる

1. `draft-gen/起動.command`（Windows は `起動.bat`）をダブルクリック
2. 開いた生成設定画面で条件を選ぶ
3. 「この内容で生成」

生成物は `mockups/{日付}_{案件名}/` に保存され、比較画面が自動で開きます。
詳しくは、ひとつ上の階層の `README.md` をご覧ください。
