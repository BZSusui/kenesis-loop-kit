Kenesis Loop Kit 使い方マニュアル

デザインのたたき台を3案まとめて作るツールです。ここでは画面の使い方を説明します。フォルダの置き方や、うまく動かないときの対処は、同じフォルダに入っている README.md のほうに書いてあります。

何をするツールか

「こんな感じのサイトにしたい」という条件をいくつか選ぶと、デザインのたたき台が3案ぶん、一度にできあがります。手で1案ずつ作っていた部分を短くするためのツールです。

できあがるのはHTMLファイルです。ブラウザで開けばそのまま見られますし、印刷やPDF保存もできます。何かをインストールしたり、サーバーに上げたりする必要はありません。

写真の部分には実物は入りません。かわりに「ここに横長の写真が1枚」「ここに丸いスタッフ写真が3枚」といった枠が置かれます。これを「アタリ枠」と呼んでいます。枠の中には、どんな写真を用意すればいいかの説明も書かれているので、そのまま撮影のメモや素材集めのリストとして使えます。

だいたいこの流れです。気に入らなければ条件を変えてもう一度作ればいいので、最初から完璧を狙わなくて大丈夫です。

できること・できないこと

先に、このツールが得意なことと、そうでないことをはっきりさせておきます。

得意なこと

  • 条件を選ぶだけで、3案ぶんのたたき台が一度にできる
  • 載せたいセクション（トップの大きな写真、お店紹介、メニューなど）を好きな順に並べられる
  • 同じセクションを2回、3回と置ける。メニューを「ランチ」と「ディナー」で分ける、といった使い方ができます
  • できあがったあとで、一部分だけ作り直せる
  • PC・タブレット・スマホでの見え方を、その場で切り替えて確認できる
  • そのまま印刷・PDF保存できる

できないこと

  • 実際の写真は入りません。写真の場所は枠になります。ただしトップの大きな写真だけは、1枚だけ入れられます
  • そのまま公開できるサイトにはなりません。デザインを決めるためのたたき台です
  • 問い合わせフォームは動きません。見た目だけです
「アタリ枠」って何ですか 写真がまだ用意できていない段階で、どこに・どのくらいの大きさで写真が入るかを示しておくための枠のことです。デザインの現場でよく使う言い方で、このツールでもそのまま使っています。枠の中に「季節の上生菓子を並べた木盆の俯瞰」のような説明が入るので、撮影の指示にも流用できます。
▲

必要なもの

3つあります。すでに入っていることが多いので、まずは動かしてみて、エラーが出たら確認するくらいで大丈夫です。

  • ブラウザ — 画面の操作と、できあがったものを見るのに使います
  • Python 3 — ブラウザとツールをつなぐ小さなプログラムを動かします
  • Claude Code — たたき台を実際に作る部分です

入っているかどうかの調べ方と、入っていなかったときの対処は README.md の「動かすのに必要なもの」に書いてあります。

▲

起動する

  1. 受け取ったフォルダを、デスクトップや書類フォルダなど、自分が使いやすい場所に置きます
  2. フォルダの中の draft-gen を開きます
  3. Mac なら 起動.command、Windows なら 起動.bat をダブルクリックします
  4. 黒い画面が出たあと、ブラウザが自動で開きます。これが操作画面です
黒い画面は閉じないでください 見た目は地味ですが、これがブラウザとツールをつないでいます。閉じてしまうと作れなくなります。作業が終わったら閉じて構いません。

ダブルクリックしても何も起きないときは、README.md の「困ったときは」を見てください。よくあるつまずきと対処をまとめてあります。

操作画面の全体像

上から順に埋めていく作りになっています。全部埋める必要はありません。案件名と業種だけ選んで、あとは飛ばしてしまっても作れます。むしろ最初はそのくらいで一度作ってみて、出てきたものを見ながら足していくほうが早いです。

項目ここで決めること
案件名保存されるフォルダの名前になります。必須です
業種文章の書き方やセクションの選び方の土台になります。必須です
カラム構成ページ全体の骨組み。1列にするか、脇にサイドバーを立てるか
本文コンテンツ構成載せるセクションと、その並び順。いちばんよく触る場所です
デザインテイスト全体の雰囲気の方向づけ
配色使う4色。決め方は4通りあります
参考にする素材「こういう感じで」と過去のたたき台を見本に指定できます
メインビジュアルトップの大きな写真。ここだけ実物を1枚入れられます
案の数3案作るか、1案だけにするか

いちばん下に、選んだ内容がまとまったテキストが出ます。ふだんは気にしなくて構いません。「生成」を押せば、その内容がそのまま使われます。

カラム構成を選ぶ

ページの骨組みです。6種類から選びます。

緑色の細い列がサイドバーです。「本文2カラム」はトップの写真は横いっぱいに広がって、その下の本文だけが2列になります。「全体2カラム」はサイドバーが上から下まで通ります。

迷ったら1カラムで大丈夫です。あとから変えて作り直せますし、実際いちばん使われる形です。

列が狭くなっても崩れません 2カラムや3カラムを選ぶと、本文の列はその分だけ狭くなります。「写真を左、文章を右」のように横に並べるタイプのセクションは、狭い列では自動的に上下に積み直されます。無理に横に押し込んで潰れる、ということは起きません。

ページ構成を組み立てる

「本文コンテンツ構成」の欄です。どのセクションを、どの順番で載せるかをここで決めます。このツールでいちばんよく触る場所なので、少し詳しく説明します。

やることは4つだけです。セクションを足す、順番を入れ替える、いらないものを消す、行ごとに中身を細かく決める。

順番を入れ替える

各行の左端に ⠿ という点々のマークがあります。これを掴んで上下に動かすと、行が移動します。パソコンでファイルを並べ替えるときと同じ感覚です。

  1. ⠿ の上にマウスカーソルを合わせます
  2. 左ボタンを押したまま、上か下に動かします
  3. 入れたい場所まで来たら、ボタンを離します

ドラッグが苦手な方や、マウスが使いにくい環境の方は、各行にある ↑ ↓ ボタンでも1つずつ動かせます。どちらを使っても結果は同じなので、やりやすいほうをどうぞ。

同じセクションを2回以上置く

たとえばメニューを2つ置いて、片方を「ランチ」、もう片方を「ディナー」にできます。それぞれの行の「設定」で見出しと説明文を変えてください。料金表を「個人向け」「法人向け」で分ける、といった使い方もできます。

置ける数には上限があります。本文のセクションは合計12個まで、同じセクションは3個までです。アクセス・お問い合わせ・サイト内検索だけは、性質上1個までにしてあります。

行ごとの「設定」

各行の「設定」を開くと、その行だけの細かい指定ができます。

項目決めた場合空のままにした場合
見出しそのまま見出しになります業種に合わせて自動で決まります
リード文見出しの下の説明文になります自動で決まります
レイアウトの形3案ともその形になります案ごとに違う形が割り当てられます
誘導ボタン「くわしく見る ＞」のようなボタンが付きます付きません
順番を自分で決めると、3案とも同じ並びになります 並び順を指定した場合、3案は同じ順番で作られます。案ごとの違いは、色とレイアウトの形で出ます。
「そもそもどう並べるのがいいか迷っている」という段階なら、並び順を決めずに作ってみてください。3案それぞれ違う並びで出てくるので、比べながら決められます。

配色を決める

色は4色で決まります。この4色がページ全体に行きわたる仕組みです。

メインが全体の印象を決める色、濃色はナビゲーションやフッターを締める色、アクセントはボタンなど目立たせたい場所、背景は本文の下地です。

決め方は4通り

① 4色を直接入れる — もう色が決まっているとき。カラーコードを貼り付けるだけです。

② メインだけ決める — 「ベースはこの色」とだけ決まっているとき。残りの3色を見つくろってくれます。

③ 配色ジェネレーターで作る — ゼロから決めたいとき。別画面で色を組み立てて、気に入った案の「モック生成画面へ送る」を押すと、この画面の配色欄に自動で入ります（貼り付けでも入ります）。

④ 見本サイトのURLから読み取る — 「このサイトみたいな色で」という参考があるとき。手順は次のとおりです。

  1. 参考にしたいサイトのURLを入れます
  2. 「配色を読み取る」を押します
  3. そのサイトでよく使われている色が、色見本になって並びます
  4. よさそうなら「反映」を押すと、4色に入ります
④を使うときに知っておいていただきたいこと 読み取るのは色だけです。文章・画像・レイアウトは一切取り込みませんし、読み取った内容を保存することもありません。
ただし、この機能だけは外部のサイトへアクセスします。社内の規程で外部へのアクセスに制限がある場合は、使う前にご確認ください。
▲

参考にする素材

過去に作ったたたき台を登録しておくと、「こういう感じで」と見本を指定できます。指定すると、その見本の色の組み立て方とセクションの並べ方を踏まえたものが出てきます。

選び方は簡単です。業種やテイストで絞り込むと小さな見本画像が並ぶので、参考にしたいものをクリックするだけ。最初は18件だけ並びます。もっと見たいときは「さらに表示する」を押してください。数が増えても画面が縦に長くなりすぎないようにしてあります。

選ばなくても作れます 見本を指定しなければ、業種とテイストから自動で組み立てられます。まずは指定せずに1回作ってみるのがおすすめです。出てきたものを見て「もう少しこういう方向に」と思ったときに、はじめて使えば十分です。

素材を追加する

画面に画像をドラッグ&ドロップすると、業種・テイスト・使われている色などを読み取って提案してくれます。そのまま登録されることはありません。提案された内容を確認して、違っていれば直してから登録してください。

まとめて入れても大丈夫です 一度に処理するのは3枚までで、残りは次の回にまわります（画面に「残り○枚」と出ます）。 1枚あたり2分ほどかかるので、多すぎると途中で失敗してしまうためです。
同じ画像を間違えて2回入れてしまっても、重複は自動で弾かれます。
登録する画像の取り扱いについて 登録した画像とその情報は、このツールのフォルダの中に保存されます。取り扱いに制限のある画像を登録してよいかどうかは、社内の規程に従ってご判断ください。迷われる場合は、AI利用管理責任者にご確認いただくのが確実です。
▲

メインビジュアル

ページのいちばん上、大きく見せる部分です。ここだけは実際の写真を1枚入れられます。

何もしなければ、ほかと同じようにアタリ枠になります。「どんな写真が入るか」の説明つきの枠です。写真がもう決まっていれば、アップロードすればそこに入ります。提案の場で実物が1枚見えるだけで印象がかなり変わるので、素材があるときは入れておくのがおすすめです。

それ以外のセクションの写真は、つねに枠のままです。

案の数を決めて、作る

3案で作ると、index-a.html index-b.html index-c.html の3つと、それを並べて見るための compare.html ができます。ふだんはこちらで大丈夫です。

1案を選ぶと index.html が1つできます。この場合も compare.html は作られますし、幅の切り替えも作り直しも同じように使えます。方向性がもう固まっていて、1案だけ手早く見たいときに使ってください。

選び終えたら「生成」を押します。数分かかります。内容の量によって前後しますが、その間はそのまま待っていて大丈夫です。できあがると比較画面が自動で開きます。

できあがったものはどこにありますか mockups というフォルダの中に、日付と案件名の付いたフォルダができます。その中の compare.html を開けば、あとからいつでも見返せます。過去に作ったものもここに残り続けるので、これがそのまま履歴がわりになります。
▲

3案を見比べる

compare.html が比較用の画面です。3案が横に並び、スクロールすると3案とも同じ位置まで一緒に動きます。同じセクションを横並びで比べられるので、「ここは案B、ここは案Cがいい」という話がしやすくなります。

幅を切り替える

画面の上のほうで、表示する幅を切り替えられます。全幅・768px・375px の3つです。それぞれPC・タブレット・スマホに相当します。

幅を狭めると、横に並んでいたものが縦に積み直されます。スマホでどう見えるかを、実機を用意しなくてもその場で確認できます。提案の場でお客様に見せながら切り替えると、説明が早いです。

▲

一部分だけ作り直す

「全体はいいけど、この部分だけ別の形にしたい」というときに使います。全部を作り直す必要はありません。

  1. 比較画面の 🔄 セクション再生成 を押します
  2. 作り直したいセクションを選びます
  3. したい形を選びます。「今と同じ」を選べば、形はそのままで別の案が出てきます
  4. 押すと、その部分だけが作り直されます。ほかのセクション・色・並び順はそのままです

1つ作り直すのに2〜3分ほどかかります。全部を作り直すより、ずっと早く済みます。

MV-01 や MENU-02 という表示について 各セクションの左上に付いている小さな名札です。同じセクションを2つ置いたときに、どちらのことを言っているのかを区別するために付いています。上から順に -01、-02 と番号がふられます。作り直すときはこの名札で選びます。
同梱の見本では使えません samples フォルダに入っている見本は、見るための読み取り専用です。作り直しは、自分で作ったもの（mockups フォルダの中）で使ってください。見本で押すと「見本では使えません」と表示されます。
▲

印刷・PDFにする

比較画面に 🖨 案Aを印刷 / PDFで保存 のようなボタンがあります。押すとブラウザの印刷画面が開きます。

そのまま印刷すれば紙に出ます。PDFにしたいときは、印刷画面の送信先を「PDFに保存」（Macでは「PDFとして保存」）に変えてください。

印刷すると、画面で操作するためのもの（セクションの名札、アタリ枠の説明文、各種ボタン）は自動的に消えます。デザインだけがきれいに出るので、そのまま打ち合わせに持っていけます。

レイアウトの形の一覧

使えるセクションは14種類。そのそれぞれに、6通りのレイアウトが用意されています。同じ「お店紹介」でも、写真を左に置くか、丸く抜くか、交互に並べるかで印象がかなり変わります。

上の図は「お店紹介（ABOUT）」の6通りです。ほかのセクションにも同じように6通りずつあります。

名前を覚える必要はありません 何も指定しなければ、案ごとに違う形が自動で割り当てられます。3案を見比べて「案Bのこの形がいい」と思ったら、🔄 でその形を選ぶ。それだけで十分です。

うまくいかないとき

まず、この3つを試してください

  1. 黒い画面が開いたままか確認する。閉じていたら、もう一度 起動.command（Windowsは 起動.bat）をダブルクリックします
  2. ブラウザを再読み込みする。これで直ることが多いです
  3. それでもだめなら、黒い画面を閉じて起動しなおす
「すでに起動しています」と出たとき 異常ではありません。二重に立ち上がるのを防いだだけです。そのウィンドウは閉じて構いません。 画面が見当たらないときは、ブラウザで http://127.0.0.1:8765/ を開いてください。

たいていはこれで戻ります。それでも解決しないときは、症状ごとに README.md の該当箇所を見てください。

こんなとき見るところ（README.md）
ブラウザに画面が出ない／「ブリッジ未起動」と出る「ブラウザに画面が出ない」
「python3 が見つかりません」「claude が見つかりません」「python3 が見つかりません」
ポートが使われている、と言われる「ポートが使われている」
作っている途中で止まる／失敗する「生成が途中で止まる」
素材を取り込んだのに一覧に出てこない「取り込みを実行しても一覧が出てこない」
作ったものが消える心配はありません できあがったものは mockups フォルダに残ります。起動しなおしても、ブラウザを閉じても、なくなりません。安心して再起動してください。
